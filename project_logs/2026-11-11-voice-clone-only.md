# 首版仅保留声音克隆

用户决定：文字试听不符合声音描述，暂时移除文字设计，只保留录音克隆。本次为桌面源码与网页示意修订，未打包发布或修改 Cloud。当前产品约定以 PROJECT.md 为准。

## 原实现与修改

原正式实现将描述拼成 `(描述)试听台词`，不传参考录音，直接调用 VoxCPM2；没有描述解析、属性校验或听感匹配评价。此前验证了生成／保存流程，没有验证描述符合度。`127.0.0.1:18026` 是独立交互示意，播放既有样本，不随描述生成。

正式界面与网页均移除「用文字创建」、声音描述与分支选择。保留「参考录音 → 双端裁剪 → 命名保存 → 用这个声音朗读台词」，录音克隆试听仍可选。继续复用 VoiceReferenceTrim、AudioWaveform、现有生成／保存恢复及安装器，没有新增组件或执行器。

voiceApi.start 不再收描述参数；原生边界对旧客户端的非空描述及无来源请求明确拒绝。Rust runner 要求实际参考文件，Python 不再拼接描述，也在加载模型前检查参考文件。历史 Job.description 继续可读，不重新执行历史文字任务；完整旧结果仍能取回。已有声音和配音保留，旧文字设计创建草稿清空，台词／所选声音保留；旧录音草稿和试听身份兼容。
