# 视频控件设计预览 · 2026-11-10

用户取消任何情况下左右不得有黑边的约束，要求用 ui-ux-pro-max 重思视频控件。现行决策在 PROJECT.md，本目录保留确认稿；正式入口已于同日接入，验证宿主见 ../video-player-live。

预览地址：Vite 下 `/scripts/fixtures/video-redesign/preview.html`。当前本机服务端口 1733。

`VideoPlayer.tsx` 是正式播放器的冻结预览副本，复用同一 lib、视频解码、截帧、拖动／键盘定位、播放和裁剪状态；仅移动细调／裁剪到工具区。样式限定 `.video-design`，不加载到正式入口。操作回调仅显示模拟结果，不写素材或覆盖视频。演示媒体在 `.tmp/video-redesign/`，为 FFmpeg 生成的 6 秒几何样片，不使用用户素材。

布局：完整等比画面居中，外壳宽度按可用空间确定；下方依次是胶片、播放／时间／音量／倍速／全屏、细调／裁剪及截帧操作。固定中心播放针及胶片拖动行为保持。取消常驻键盘说明文字；title、无障碍名称与原快捷键保留。窄容器按组换行，仅折叠音量滑杆，静音入口保留。

Skill 检索采用 ux 域。命中播放控制／可见焦点和响应式无横向溢出原则；未检索到专门的桌面播放器工具条模板，具体分组是针对现有功能的设计判断。沿应用工业主题、工程蓝和细边线，不引入其他视觉系统。

验证：Chrome 独立预览通过竖屏／横屏／方形、深浅主题、390px 窄容器／视口、播放暂停、裁剪展开，无浏览器异常和横向溢出。截图在 `.tmp/video-redesign/`。已人工查看深色竖屏、浅色窄容器和窄视口。仅设计预览，不代表正式应用及 Mac 原生验收。

第二版按反馈调整：裁剪在全片胶片两端拖动手柄，区间外压暗、保留区间描边、播放针独立；保留起止秒数输入及手柄方向键作为拖动替代。音量改细线方柄；倍速取消原生 select，点击当前倍率展开横向六档按钮。样式沿主题，不照搬 iOS 黄色。实际浏览器验证手柄拖动／键盘、数值输入、所选区间播放、倍速切换、深浅主题和 390px 无横向溢出通过；正式入口仍未改。

第三版纠正倍速理解：用户接受下拉交互，只要求改样式，明确禁止增加高度。删除第二版横向展开行，复用正式 `TacticalSelect` 及 TacticalMenus／IndustrialMenus 样式，菜单 portal 悬浮覆盖，不参与播放器布局；播放快捷键避开 combobox／listbox，保留菜单自身键盘导航。

第三版验证通过：1280px 深色与 390px 浅色，展开／选择后播放器、画面、控件、播放栏、操作栏的 x/y/宽/高完全不变；选择、方向键／End／Enter、Esc 返回焦点、点击外部关闭，无横向溢出或浏览器异常。截图 `speed-v3-dark.png`／`speed-v3-light.png`。

第四版：删除独立细调按钮，普通胶片和裁剪手柄复用 `fineScrub.ts`。按住至少 400ms，在原落点 3–12px 范围内轻拖进入四倍细调；大幅移动先发生则本次保持普通拖动。按增量位移切换精度，不重新计算此前拖动，松手／取消／失焦退出。普通胶片细调时四倍展开但不增加高度，保留全片胶片避免拖动中出现空白；裁剪手柄保持全片范围，以细描边反馈精度状态。Shift+方向键仍可 0.01 秒微调。数值是本应用预览参数，不宣称为 iOS 官方阈值。

第四版验证：3 项纯逻辑测试和实际浏览器长按／阈值／四倍位移比例／快速拖动防误触／松手无跳变／失焦复位／裁剪手柄通过，无浏览器异常，截图 `fine-v4-dark.png`。该记录为确认前的预览验证；后续正式接入与回归见 project_logs/2026-11-10-video-controls.md。
