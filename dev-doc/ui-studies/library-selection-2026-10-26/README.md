# 素材多选动效预览 · 2026-10-26

已于 2026-10-27 经用户确认接入素材库共用组件；此目录保留独立确认稿和预览工具。当前产品约定与发布状态以 `PROJECT.md` 为准。

启动：`node dev-doc/ui-studies/library-selection-2026-10-26/serve.mjs`，打开 http://127.0.0.1:17867。

- 点击素材选中或取消，左侧黑底标记、重播按钮可重播所有选中项。
- 300ms：两侧括号从中心展开到图片外侧、白色准星的四条线独立旋转至指向素材四角、上下短竖条／左右短横条从中心外移、中心方框及十字渐现；后 160ms 使用现有悬浮的两次短闪节奏，结束后静止。
- 2026-10-27 修订：仅选中图片等比缩小至 88%，取消后恢复；卡片占位保持不变，素材间隔对齐实际瀑布流的 8px。左右括号及四向短条位于缩小后的图片外侧，避免压图或侵入相邻卡片；中心方框和白色准星仍覆盖图片。
- 准星四条线与中心方框断开，线段从距中心 20px 处开始；终态方向按图片实际宽高比计算，横图角度更平、竖图角度更陡，尺寸变化时同步更新。旋转期间也保持中心间隙。
- 支持四分之一慢放、逐帧查看、深浅主题及减少动态效果。
- 示例图片复用已有画布独立预览素材；参考图来自本次用户附件。没有外网资源、真实素材库读取或原生 IPC。

本页控件只用于预览；正式实现保留应用现有多选操作、共享卡片和虚拟化语义，没有复制预览工具到产品。

示意验证：`node dev-doc/ui-studies/library-selection-2026-10-26/preview-ui.test.mjs` 通过。覆盖四条白色线段指向图片对应四角、与中心方框保持间隙、宽高比变化与窗口缩放后方向同步、完整括号及四向短条在图外、短条方向、相邻多选与悬浮不重叠、8px 间隔、图片等比内缩及取消恢复、卡片占位不变；同时保留 0／75／150／225／300ms 定格、双短闪、终态稳定、快速多选取消、装饰点击穿透、1280／390px 深浅主题、零滚动条占宽及减少动态效果验证。确认稿截图位于 `screenshots/corner-rays-2026-10-27/`，前两版截图保留。
