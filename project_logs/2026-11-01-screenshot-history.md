# 2026-11-01 截图历史、标注与自动入库

源码待发布。本轮不重启真实桌面、不读写用户素材库／剪贴板，不调用付费服务。

## 产品行为

- **历史**：只有成功完成的截图结果进入历史，包括标注；本机保存，重启可读取。最多 50 张／256MiB 原图 PNG（缩略图另占少量空间）。设置与截图栏均可打开历史；可看原图、前后浏览、复制、保存、再次钉住、删除或清空。清空要求确认，不影响已经入库的素材。不保存被取消的完整屏幕，不声称能恢复旧截图的可编辑标注对象。
- **自动入库**：设置 → 个性化与记忆 → 截图工具，默认勾选“截图自动保存到素材库”；旧设置缺字段也为开启，显式关闭会保留。复用现有入库路径和精确去重，重复图片不覆盖旧来源。只在完成截图后入库；钉图／历史重输出不重复入库，不自动启动远程分析或收费任务。
- **钉图**：恢复原生悬浮阴影，右上／左下 4.8px 方点；无常驻工具栏、无额外图片留白。装饰独立于导出像素。
- **标注**：矩形、椭圆、直线／折线、箭头、画笔、荧光笔、文字、马赛克、高斯模糊和橡皮擦；形状支持实心，文字直接画面内输入。滚轮／1、2／方括号调笔宽，Tab 切线与箭头，Shift 约束方向或形状，右键结束当前标注，Ctrl／⌘+Enter 完成文字，撤销重做保持。
- **Esc**：无需先点击截图；空选区、输入焦点、拖动和加载阶段都能退出。历史弹层优先关闭；已经明确提交的输出由后端串行完成，取消不与存储交错。

## 操作与根因

1. 按 ub-mode 复核当前文档、文件工作区入库与错误提示边界，查阅 Snipaste 官方基础工具／快捷键。序号属于 Pro 范围；未把未实现的对象重编辑、旋转缩放等高级操作描述为已对齐。
2. 定位 Esc：旧前端使用冒泡监听，子层可吞键；Tauri `WebviewWindow.set_focus` 只处理顶层窗口，不等于 WebView2 内容获得键盘焦点。改捕获阶段处理并显式聚焦 WebView 与截图根。先复现旧监听被子层阻止，再验证修复。
3. 历史采用原子 PNG／缩略图／清单发布，最后发布清单；严格 ULID 身份访问，不接受任意路径。数量和字节预算清理可重试；清空只处理本目录的合法历史文件，包含半写／半删残留。
4. 输出使用串行锁和每会话完成状态。复制／保存／钉图完成后记录历史和入库；入库失败保留同一输出，重试只续存。部分完成后更换动作／图片会明确拒绝，避免误把旧图当新结果。保存对话框取消不记成功。
5. 独立历史面板复用 `ModalShell`；修复原图浏览切换后的焦点，图片 URL 在卸载时释放，展示错误转换为中文。先取得旧设置缺少开关和缺失默认值的红灯，再补实现。
6. 标注做实际像素验证，修复新文字输入被默认 pointer 焦点立即 blur 的问题。复现未结束折线直接输出会漏标注后，改为在临时导出画布合成草稿，保存取消仍能继续编辑；同时去掉完成文字后强制聚焦引发的二次 blur 叠画。草稿与完成后 PNG 逐字节一致。钉图装饰只在 UI 层，图片输出不带方点或阴影。
7. 未创建工作树或清理其他任务文件。crapper／dryer／mutator 工具不可用，采用专项行为测试、实际像素及原生验收。只提交本轮代码与文档，排除同时进行的外部拖动等改动。
