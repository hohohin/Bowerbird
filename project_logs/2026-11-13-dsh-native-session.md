# 2026-11-13 DSH 云端会话

用户确认由云端 harness 管理会话历史，并授权在验证后发布。部署范围包括聊天数据库、chat-proxy、chat-worker，以及运行 DSH 的 VPS Worker 和会话持久卷。桌面需要配套更新才会发送 v2 请求。

### 实现及隔离验收

- 手动运行卡片和从详情发送消息使用同一云端会话，点击「新对话」后分配新身份。桌面只提交当前用户消息、素材别名和当轮技能选项。旧客户端保留原协议；旧本地聊天不自动导入，桌面详情标明云端记忆起点。自动工作流的每个输入独立运行，不创建长期会话目录。
- 服务端按经鉴权的账号和会话 ID 分配原生会话键；同一会话串行，不同账号可用同名会话。每次提交仅关联上一成功轮。Worker 新进程通过 DSH 的 `agents.resume` 读取其原生记录，完成时等待 DSH 写盘。私有技能由服务端按当前轮的权限装载。
- 钉版 DSH 的独立进程测试覆盖创建、恢复、再次恢复、跨账号和新会话隔离。约 7.3 MB 的合成长历史触发 DSH 自带的压缩；确认了独立摘要模型调用与下一轮恢复。该测试的模型端为隔离夹具。六项桌面 VPS 原生用例、17 项对话状态测试及 Chromium 会话迁移提示验收通过。另用真实 SQLite 写入 40 轮问答，确认第 41 轮仍使用第一轮的会话 ID，而请求体只有第 41 个问题及本轮素材引用说明。
