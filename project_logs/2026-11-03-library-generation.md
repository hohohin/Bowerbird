# 素材库直接创作与完成通知

## 目标与边界

- 用户要求素材库复用画板完整创作框，上方选择项目，未选项目时归入同一个「快速生成」项目。
- 发送后留在素材库；完成通知可点击进入所属画板和任务，并提供可回看的近期任务区。
- 按 ub-mode 分步验证：先补行为失败用例，再实现最小改动，最后集成回归；不调用真实模型或读写用户素材库。

## 行动记录

1. 读取 PROJECT 当前约定、项目画板、架构入口、UI 规范、错误展示及 ub-mode，确定复用 CreativeComposer 和已有任务导航。
2. 检查 Git 状态：工作区已有项目新建卡片及测试等未提交改动，保留这些变更；本任务仅按明确文件清单提交。
3. 并行划分默认项目持久化、素材库创作框、通知与近期任务三条工作；主线程负责集成、端到端验证和交付记录。
4. 现有通知只支持文本，已有后台任务和精确 project/thread/node 导航；扩展现有入口，不另建任务执行器。
5. 默认项目使用唯一系统 workspace_key，与可编辑名称分离；事务内创建项目与画板。默认目录不可写时走已有资料目录选择流程，重试冻结目标。
6. 通知扩展为可点击动作并保留提示音／弹窗开关，聚焦或悬停时暂缓消失。近期任务从既有普通生成、Agent、对话及 H3 状态投影，不创建第二套执行队列。
7. H3 入口从原画板提取为共用函数，先保存卡片再启动原运行时；通知等待持久化确认。工作流定位按实际执行线程归属核验。
8. 界面先独立预览；按用户两轮反馈将项目入口移入生成框、最终与模式切换同排，取消额外空白行与菜单双层边框。
9. 审查修复发送期间新聊天草稿被误清、卸载后旧回执覆写新草稿、默认历史串到显式项目；旧完成通知冻结原轮次定位，不随下一轮漂移。
10. 主屏标签／集合点选接入既有引用事件，保留浏览、修饰键多选与文本详情；多选时为原操作条留出空间。
11. 开发期间检测到另一路画布图片单双击改造，保留其文件／代码与文档；提交时按本任务精确差异选取，不包含其改动。
12. 用户明确回复「按这个版本接入」，确认项目入口与模式切换同排的紧凑版本；随后接入正式 App／HomeWorkspace，并核验完整首页路由。
13. 独立审查复现并修复旧聊天回执关闭新挂载创作框的选择状态；删除 H3 卡片／运行及定位记录裁剪时清除任务投影，迟到更新不复活已删除条目。新增行为回归均先失败后通过。
14. 正式主屏按创作框实测高度保留列表滚动空间；全局协调器跟随 App 生命周期，隐藏项目页和进入画板后卸载主屏编辑器，避免两处消费素材引用事件。
15. 最终逐项核对提交清单；CanvasWorkspace、素材库两组件和 PROJECT 只选取本任务差异，其他聊天改动及临时构建／截图保留在工作区。代码、测试、现行约定及里程碑同次提交，旧第三条里程碑原文移入进展归档。
