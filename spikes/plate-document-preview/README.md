# Plate 文档独立预览

状态：2026-11-02 方案确认后的第一阶段，可操作网页待用户确认。未接入正式素材库。

## 启动与验证

在本目录运行：

```powershell
npm ci --ignore-scripts
npm run dev
npm test
node ui.test.mjs
npm run build
```

网页为 `http://127.0.0.1:17924/`，只监听本机。UI 测试默认连接这一地址，使用仓库既有 `apps/html-renderer` 的 Playwright 与本机 Chrome；可通过 `DOCUMENT_PREVIEW_URL` 覆盖地址。Windows 沙箱可能阻止浏览器访问回环地址或 Vite 的 realpath，需按工具权限正常运行，不能将环境拒绝计为产品失败。

## 可操作内容

- React 18 + 真 Plate 编辑器：正文、源码、标题、列表、引用、加粗、斜体、撤销、重做。
- 左侧可点击或拖入图片、音频、视频，拖入使用鼠标所在段落；素材说明可编辑。媒体保持原比例，音视频不自动播放。
- 音频采用一个共享播放器及预生成真峰值。悬浮时间针、点击位置临时试听、移出结束；按钮从头持续播放，移出不结束。其他临时接入的音频只显示真实播放条，未声称完成原生波形生成。
- `.md`、`.markdown`、`.txt` 文件可只读打开到隔离内存草稿。纯文本保持普通文本，明确点击后可建立另一份 Markdown 草稿，原文本条目保留。
- 整篇或勾选段落可转发至对话、Agent、生图、视频草稿。正文顺序、说明及原素材身份保留；多次转发保留独立草稿，可从底部切回，不覆盖已有编辑。
- 缺失素材阻止带入；不兼容附件保留并明确提示。预览中对话/Agent 按本机图片入口示意，正式适配必须依据实际 provider 与模式判断，不能把示例能力表直接复用为生产规则。

## 隔离边界

- 保存仅保留本页草稿，刷新重置；没有原文件写入、素材库登记、模型调用、上传或扣费。
- 原有示例图与视频从仓库样例引用，不复制用户素材。`public/pulse.wav` 是本轮生成的 8 秒合成测试声音，`scripts/generate-audio-fixture.mjs` 可重建对应 256 桶峰值。
- 未支持的 Markdown 表格、任务列表、frontmatter、复杂列表、HTML 等保留源码。本阶段未实现表格富编辑或执行 MDX。未登记图片链接不自动请求外网，也不按文件名猜素材身份。
- 预览媒体引用语法只验证资产身份往返，不直接作为正式可移植文件协议：生产保存还需关联原路径、外部变化检测及跨设备定位规则，不能依赖内存 URL。
- Plate 与所选插件许可及固定版本见 [DEPENDENCIES.md](DEPENDENCIES.md)，未使用 Plate Plus 模板/组件，未修改主应用依赖或锁文件。

## 验证结果

- 7 项 Markdown 与 9 项转发逻辑测试通过，有真实 RED→GREEN 记录。
- Chromium 验证实际 Plate 输入、源码往返、同模式不覆盖、点选/拖放插入及撤销重做、真实音视频播放、整篇/选段转发、独立草稿恢复、文本文件打开、缺失引用阻断与源码安全；全程无外部请求、模型调用或 POST。
- 深浅主题 800、900、1440px 检查通过；截图输出到 `.tmp/ui`。本机内嵌浏览器已显示预览并人工核对媒体播放。
- 独立 TypeScript 与 Vite 构建通过。预览当前编辑器 JS 约 1.31 MB（gzip 399 KB），构建提示大块；不代表千图素材库、长文档或原生性能已验收。正式接入应按打开文档时加载编辑器，列表只渲染摘要。
- 完成时隔离依赖 `npm audit` 为 0；crapper/dryer/mutator 未提供，不声称执行这些工具。
