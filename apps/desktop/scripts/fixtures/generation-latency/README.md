# Bowerbird 与官网生图计时

用浏览器直接打开同目录的 [index.html](index.html)。页面可以读取本地录屏，也可以接受外部播放器里的秒数。每一对录屏导出一个 JSON，页面刷新会清空表单。

## 录制

1. 在同一电脑与网络上，分别打开项目生成会话和供应商官网。在两端使用同一订阅账号，记录匿名账号代号、会员档位、客户端版本、实际显示的模型、尺寸或画幅、质量和张数。每一对只生成一张。Codex 与 ChatGPT 无法核实相同底层模型时，保留“未能核实”。
2. 为提示词、参考图文件及顺序、新会话或续轮条件指定同一案例编号。控件未提供的参数填“未知”。同一案例奇数轮先桌面、偶数轮先官网。在相近时段交替操作。每轮提交前在对应任务列表核实同账号其他任务，分开记录空闲、已有任务或未知。
3. 录下用户实际使用的画板或会话详情，以及官网对应的生成界面。从提交前开始，持续录到原图出现。两端均使用同一套终点验证动作。优先录制普通创作过程中的案例；测试工具自身只处理录屏。

## 标出三个时刻

| 时刻 | 在录屏中核验的画面 |
|---|---|
| 点击提交 | 提交动作发生的第一帧。录制时开启点击高亮，或统一取发送按钮响应帧。 |
| 首次看见本轮图片 | 本轮新产物首次可辨识的画面，允许低清或生成中预览。占位图、参考图和上一轮的成品均跳过。 |
| 完整原图可用 | 预先选择同一终点。默认两端都在结果可操作后立即打开完整分辨率图片，取原图实际显示帧，并核对尺寸。也可统一取原图下载或导出到本机完成帧。所选终点保存在 JSON，两种口径分别汇总。 |

桌面可以观察项目生成卡或会话详情中的首图。正式结果可打开原图核实。官网也要验证“查看原图”或原图下载，避免把放大的缩略图计作完整原图。录屏缺帧、任务失败或终点未观察到时，留空该项并在备注说明，保留这次尝试。同一帧已经见到并能使用原图时，两栏可以相等。

## 读结果

页面按各自录屏的起点相减。配对差值为 Bowerbird 耗时减官网耗时，正数表示桌面多等的秒数。JSON 保留原始录屏时间、证据编号、对照条件和缺测原因，方便复核。报告时列出每种条件下已尝试、完成配对和缺测的次数；在相同案例、模型匹配情况、原图终点及忙闲条件内，分别计算首图、原图的配对差值中位数。样本少时一并列出单次差值。模型或队列未知的样本单列。

原生生成诊断的登记、入库和完成时间可用于事后解释区间。首图帧只能由真实客户端画面验证；录屏精度受帧率限制，手动打开或下载原图也会带入操作时差。
