# Plate 多媒体文档与草稿转发：独立预览

## 授权与范围

- 用户确认采用 Plate；文本素材可插入图片、音频、视频，并携带文字和原素材引用转入对话、Agent、生图、视频卡片。
- 用户明确选择先带入草稿，再手动发送或生成。已有文件只连接，不复制；文档移除媒体块不删除原件。
