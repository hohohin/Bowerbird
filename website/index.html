PROJECT WORKSPACE

一个项目，
就是一套视觉上下文。

把同一品牌、客户或创作主题的参考图、反推维度与生成结果放进独立工作区。创作时只看当前项目，风格不串线，素材也不用重复存。

FAQ

常见问题，
一次说清。

素材会上传到 Bowerbird 云端吗？

不会。图片、缩略图、SQLite 数据库、提示词与分析结果都保存在你选择的本地素材库目录中。AI 分析和生成会通过你自己的 provider 账号联网执行。

不会写提示词，也可以使用吗？

可以。收集后的图片会被拆成可选维度；创作时只需写中文意图、选图、点维度，创作板会组装完整 prompt 和参考图。

AI 功能需要什么账号？

反推使用你的 ChatGPT 订阅（经 codex CLI）；生成支持 codex，也可以切换即梦。未登录时素材管理仍可正常使用。

支持哪些平台？

Windows x64 已开放公开 Beta；macOS 版本即将推出。浏览器扩展支持 Chrome 及兼容 Manifest V3 的浏览器。
