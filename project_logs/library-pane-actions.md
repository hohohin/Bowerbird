# 素材库分栏控件实装记录

## 确认与范围

用户否定「关闭按钮右侧加号」候选，明确要求原分栏图标居中压在相邻两栏的分界线上，左右各占一半。修正后的独立预览获「采用这版，继续实装」确认后接入。单栏右上显示分栏，多栏各栏右上显示关闭；分界按钮在当前位置插入左栏浏览状态的独立副本。

## 动作与原因

1. 阅读项目约定、架构入口、界面规范并使用 ui-ux-pro-max，沿用现有 Lucide Columns2 图标与视觉样式。
2. 在 `scripts/fixtures/library-pane-actions/` 制作封闭合成素材预览，先验证用户纠正后的按钮位置与操作；候选 CSS 与正式组件按查询参数分开懒加载，避免候选样式让正式测试误通过。
3. 正式组件测试先红：单栏仍有关闭按钮，数量断言 `1 !== 0`；随后调整 LibraryHome／LibrarySplit，删除旧工具栏分栏入口，加入分界按钮和单栏右上入口。
4. 分界按钮与调宽 separator 作为兄弟节点，保留指针捕获、双击与键盘调宽；调宽从外层分界容器获取相邻栏宽度。
5. 独立审查发现原关闭按钮右距 8px 与跨界按钮重叠 3px；多栏右距改为 16px，导航同步预留 52px。测试直接检查左右半区命中与关闭按钮不重叠。
6. 文本浏览回归因控件腾出空间、不再固定出现「更多」而失败。测试改为按折叠状态决定是否展开，图片／文本切换、独立浏览状态和编辑器断言保持，重跑通过。
7. 更新确认稿说明与 PROJECT 现行约定；只纳入本任务文件，保留其他任务改动。沿用用户仅保留本地提交的选择，不推送。
