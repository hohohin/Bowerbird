# 首页选择记忆与项目返回

## 决策与实现

- 用户要求素材库／项目选择跨应用重开保留，退出画板先回项目管理；复用现有 `libraryHomeView`、`exitProject` 和本机 localStorage，不新增页面、设置或原生路由。明确从探索顶栏选择素材库时，沿用 App 的保存屏障，成功后去素材库并记住选择。
- 启动只接受 `projects`，无记录／无效值／存储不可用回退素材库。状态订阅仅在有效首页目的地改变时写入 `bowerbird.libraryHomeView`；项目内始终记为项目目录，素材过滤／定位不会覆盖它。
- `exitProject` 在草稿保存及原生 scope 清空成功后一起提交项目目录目的地；失败保留当前画板。没有打开项目时调用 exit 不改当前首页选择。
