## 行动与原因

1. 阅读 PROJECT 当前状态／关键约定、Seedance／Cloud 视频／H3 专项及 UI 规范，确认四模式、比例与历史恢复边界。

3. 将创作框和详情编辑接入推断值，菜单只保留「自动识别／首尾帧」。实际模式留在已有控件提示中，比例控件随模式变化，不新增工具栏行。
4. 工作流真实 controller 先复现「旧单图模式无图仍报需要 1 张图片」，再按最终编译引用推断。抽出既有视频图片端口识别供预览复用，避免预览把实际 PNG 尾帧误当视频。仅连接未引用的素材不计入。
5. 编写正式组件隔离浏览器测试：先看到旧菜单「文生视频」与预期「自动识别」不符，再验证引用增删、单图／多图／视频、显式首尾帧、回自动、音频拒绝和详情续轮。测试夹具修正视频续轮按钮名称，并在每次发送退出编辑后重新打开，未为夹具改变产品行为。
6. 复核源码 diff 和 TypeScript；独立子代理复核提交、历史重试与 H3 分支，更新 PROJECT 和专项证据。仅暂存本轮文件，保留其他线程工作区修改。
