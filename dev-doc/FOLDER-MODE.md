- 2026-10-19 界面收敛：文件浏览器的目录导航并入应用顶栏、搜索右缩，刷新内嵌地址栏；全局素材不显示地址栏或占位，其刷新入口放入更多菜单；位置／颜色／更多圆形按钮位于来源切换块右侧；具体产品约定以 PROJECT.md「文件浏览界面收敛」为准。图片／视频卡片仅展示媒体，文件夹保留名称。原素材大小滑块固定右下角，选择媒体后才显示操作条；点击地址空白处进入编辑，支持 Enter／Esc／失焦及 Ctrl／Cmd＋L，兼容盘符根、UNC 共享根和 POSIX 根的层级导航。
- 文件浏览器与全局素材位于顶部悬浮切换条；原全局索引通过“历史素材”兼容入口访问。支持长按排序，本机独立记忆新两视图的顺序。画板中 Tab 默认打开项目素材，继续按 Tab 在项目素材／全局素材／文件浏览器间循环，Esc 返回画板（弹窗及地址编辑优先）。保留原素材库组件及其搜索、筛选、选择、项目展开和滚动状态；目录模式拥有独立搜索、选择、历史和标签。
- 文件夹优先，媒体采用现有瀑布流布局和缩略图大小控件；单击选择，双击/Enter 进入目录或预览图片、视频。当前层列举，不混入子目录媒体。
- 主区滚动条悬浮于右缘，不占横向空间；滚动、悬停或键盘聚焦时显示，支持拖动/滚轮/键盘。显隐不得改变素材宽度或列数，关闭后仍恢复主库滚动状态。
- 选中分类标签后，主区切换为纯图片瀑布流，汇总当前目录及其子目录内属于该分类范围的匹配图片；不展示文件夹和视频，也不混入上级或同级目录。搜索继续过滤这些结果，预览、多选、人工示例及显式引用/复制使用图片原始路径；悬停显示完整路径以区分同名文件。点击索引中的清除图标或再次点击已选标签恢复当前层目录列表，切换筛选清除旧选择。
- 标签查询只检查记录内匹配图片的存在及目录归属，不读取全量图片内容、不写分类记录；跳过已删除图片、符号链接及已建立独立分类记录的子目录。查询失败显示错误，快速切换或清除标签后不接纳旧请求结果。
- 目录导航提供路径输入、选择目录、返回、上一级和刷新；通过同一悬浮条切回素材来源，画板内也可用 Esc 或返回按钮关闭素材界面。打开失败保留可返回的位置，迟到请求不能覆盖新目录。
- 图片支持 PNG/JPEG/WebP/GIF/BMP；视频支持既有 MP4/MOV/M4V/WebM/MKV/AVI，播放取决于 WebView 编码支持。封面失败显示视频占位，不阻止浏览。
- 浏览/预览/分类不登记到主库，不复制原媒体。显式加入画板才登记外部资产；显式复制到素材库才复制原文件。目录模式不提供磁盘删除/改名。

## 分类契约

- 本机目录与素材库共用 `TagIndex` 右侧标签索引：拼音排序、边缘唤出、纯文字蓝色选中、连续悬停放大和键盘定位均一致，不占瀑布流宽度。目录使用标签 ID 筛选，不改主库搜索、标签或选择。
- 顶部「更多 → 管理分类数据」和索引底部管理图标直达管理视图：新建／编辑名称和说明、停用自动匹配、单个／批量删除及所选图片正反例。手工管理不依赖模型安装，自动分类设置仍单独进入；使用当前目录解析后的分类根，继承上级记录时修改的是该共享范围，独立分类目录与主库隔离。关闭管理后刷新索引，删除当前标签自动恢复目录列表，写入失败保留错误反馈。
- 自动分类可选择素材库或文件夹。选定根目录，可选包含子目录；只分类图片，原地写 `.bowerbird/classification.json`。
- 文件身份使用根目录相对路径和内容指纹；记录仅包含版本、扫描范围、标签/说明及后台分类维度、归属来源、人工正反例和模型观察，不含凭据、主库 ID 或机器绝对路径。
- 复用现有本地/Jev+Cloud 引擎，在独立内存数据上下文运行，所有候选词、正反例和结果均限定为当前目录。设置及模型安装沿应用现有配置，Cloud 沿既有上传/计费说明。
- 2026-10-18 分类沿主库统一候选规则：所有启用标签加无匹配项，原始概率前四且 ≥30% 才选入，无合格项由 Cloud 补标签，不设维度配额。目录记录的可空 dimension 保留兼容，但不再排除候选；旧 JSON 缺字段可读，不向主库同步。前端标签仍平铺。
- 分类逐图提交，保存用临时文件刷盘再替换。单个分类目录只允许一个写入者；未获锁、失联或保存失败明确报错，不声称完成。源记录不可写的 PermissionDenied/只读文件系统错误转为本机持久记录；损坏记录和已存在写锁不当作权限不足。本机回退仍有单写锁，源分类文件保持原样。NAS 真机锁与断线行为须另验。
- 子目录继承最近祖先的分类根（仅当该根开启递归）；显式建立的独立子目录分类根优先。扫描跳过嵌套分类根和符号链接，避免范围重叠及目录循环。
- 新增/内容变更进入待处理；变更清除旧自动判断，保留人工归属，人工示例内容变化需重新确认；重命名暂按新路径处理，不凭同名猜测身份。
- 首版显式扫描，不增加目录后台监听或多机协同编辑协议。

## 文件优先第一阶段实现（2026-10-19，未发布）

产品范围与未完成项以 PROJECT.md 对应关键约定为准。本节列技术入口与验收边界。

- `core/file_workspace.rs` / `commands/file_workspace.rs` / `lib/fileWorkspace.ts`：配置独立于旧 library_root，持久记录默认根、明确添加位置及项目 ID→目录。首次建项目做写入探测；旧项目映射不随根设置更改迁移。空白画板仍延迟写入项目数据库，但创建时即预留真实目录。尚未写内容便丢弃的画板可能保留空目录。
- `LibraryPaths::for_project` 冻结具体保存目录；`asset_store_path` 统一走该目录或收集箱。已登记文件从文件浏览引用时复用素材 ID；删除保护只认可应用创建的目录，不把“添加位置”当作拥有其文件的授权。缩略图与 SQLite 仍在本机旧库根。
- `file_workspace_all` 递归汇总明确位置、默认根及已创建项目目录，规范化路径去重，跳过隐藏目录和链接；离线结果与正常结果分别返回。当前为整次枚举，尚无增量监听/索引及中途取消；大 NAS 性能待实测。
- `folder::Session::open_with_storage`、`view_with_storage`、`tagged_images_with_storage` 共用记录定位。可写时沿用 `.bowerbird/classification.json`；无权限时转到本机 `local-classification/folder-records/<源规范路径 SHA256>/`，`source.json` 保存来源，记录结构仍使用相对图片路径。Windows 来源键忽略大小写；没有承诺识别不同挂载别名。该目录独立于可删除的模型包，属于持久用户资料。父子分类范围仍按独立记录边界隔离，个人本机记录优先；权限恢复不自动合并。
- `0038_creative_file_queue.sql` 在图片、分析、标签及关联提示词修改事务内登记待写 token。`core/creative_files.rs` 后台每三秒处理最多 64 项，按 token 条件确认，避免抹掉导出期间的新修改；成功写入图片同目录 `.bowerbird/<asset-id>.json`，无权限/路径不可用时持久写到 AppData（debug override 为隔离根）的 `creative-records/<asset-id>.json`，附来源路径。两处均失败时保留队列 error 供重试，SQLite 原资料不丢失。已有本机副本继续作为导出目标；不会自动回写远端覆盖他人资料。没有启动时批量导出旧库，只有后续修改进入队列。
