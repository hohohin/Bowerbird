# 文档两栏布局与段落 Agent

1. 读取 ub-mode、界面技能及项目／文本／工作流／聊天／统一 Agent／账号／错误提示约定。核对现有画板 Codex CLI 和 Cloud DSH 文本任务契约，明确 DSH 不是 DeepSeek 普通聊天。
2. 先修改布局行为测试，确认默认收起不符合新要求；补 Agent 真实组件测试，确认缺少入口。恢复素材库默认展开、两侧全高；将整个编辑面板而非仅正文平滑让位，保留工具栏高度测量避让侧边把手。
3. 给 Plate 工作区增加可选 Agent scope，在当前选区的顶层段落左侧提供入口。原详情编辑器不启用该入口；Alt+Enter 仍定位段落操作按钮。
4. 复用 ModelSelect 与额度显示，使其 portal 遵循嵌入工作区边界。气泡使用已有视觉变量，验证深浅色与 900／1440 窗口；修复菜单被气泡挡住和侧边把手被换行工具栏遮住的问题。
5. 使用既有 Codex CLI 请求／取回／取消 IPC，以及 Cloud DSH textRewrite／text.result。Cloud 线程归属、账号匹配、测试账号、allowlist 与并发检查保持；查询／取消走共享单 run 操作队列。未变更原生、云端、计费或模型配置。
6. 回写按节点 ID＋快照定位，Markdown 插到目标之后并更新后续锚点。段落手改／删除时保留结果，支持显式插入。气泡仅传当前段落与自己的对话历史；每次 Codex 会话隔离，不复用其他卡片上下文。
7. 请求生命周期单独管理。读取失败仅取回原请求；停止、关闭或切换气泡使旧请求失效，迟到创建的任务也取消。取消未确认会提示；本机投递状态未知仍保留原请求身份。
8. `text-agent-ui`、`text-workspace-layout-ui`、`text-block-editing-ui`、`text-library-ui` 通过；包括两通道、连续写作、格式与撤销、并发修改／删除、任务身份、Cloud 非文本／失败／无效结果、停止失败、启动中关闭、账号变化、素材插入后继续输入与提示词复用。TypeScript 与独立 Vite 构建通过，保留既有 chunk 大小及 api 动静态导入提示。
9. 使用官方 crapper／dryer／mutator；覆盖率由真实浏览器各场景 V8 数据转换，质量扫描限本次 Agent 三个新 TS／TSX 文件：行覆盖 99.28%、分支覆盖 90.76%，全部函数 CRAP 小于 10（最高 9.6）；dryer 阈值 0.8 无重复。取消／迟到回写的 5 个定向变异全部 killed，原始副本基线通过、无超时误判；其余变异未宣称全量执行。详细覆盖率与 CRAP 结果位于 `.tmp/text-agent-quality`，截图位于 `apps/desktop/.tmp/text-agent`。
10. 检查最终任务 diff，只纳入本次文本相关文件；保留并发工作区其他修改。未创建新 worktree；本次截图、构建与质量副本保留供复核，不清理他人临时目录。项目约定与文本专项同步更新。
