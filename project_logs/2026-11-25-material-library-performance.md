# 素材库体验与性能验证

## 30 万条平铺概览

在同一台 Windows 主机运行前后两版 `core::catalog_browser::tests::benchmark_300k_catalog --ignored --nocapture --exact`。使用相同的 Cargo 默认测试配置、进程内 SQLite、30 万条合成素材和 60 万条素材标签关系。两版均先查询偏移 0、150,000 和 299,940 的分页，再计时一次 `catalog_overview(kind=all)`。两次测试顺序运行，耗时各取一个样本。

| 指标 | 优化前 | 优化后 |
|---|---:|---:|
| 组图后素材总数 | 300,004 | 300,004 |
| 概览耗时 | 3,496.32 ms | 456.95 ms |
| JSON 响应 | 248 字节 | 100 字节 |

本次基准的概览耗时下降约 87%。平铺只计算总数，标签模式继续读取完整汇总。从标签模式进入搜索时，侧栏可使用已读或在途的标签汇总。对应入口见[桌面复用地图](../dev-doc/reuse/DESKTOP.md#在新面板里嵌入独立素材浏览状态)。

## Windows 和浏览器回归

- Windows Shell 使用默认文件夹枚举标志时仅返回普通目录，加入包含隐藏项的标志后也返回 `.bowerbird` 和 `.bowerbird-quick-transfer`。本轮未切换系统显示隐藏项目的用户设置。拒绝 `FILE_WRITE_ATTRIBUTES` 的临时 ACL 夹具验证了业务可继续写入目录内容。
- Windows Rust 定向回归 219 项通过，覆盖内部目录、只读分类降级、迁移、分身内容和修改时间、目录内外的相对目标路径、概览及画板查询。10 项隔离基准按原标记跳过，本页的 30 万条基准单独执行。
- Chromium 导航、项目范围、关键词搜索、分页、连接文件夹、缓存、素材菜单和随图资料对话框通过。搜索夹具覆盖 IME 合成期的拼音及确认键、上屏后单次提交、清空与取消待提交输入。项目菜单覆盖有实例、无实例和读取失败，断言只调用新的存在性查询。
- 历史 `library-pages-ui.test.mjs` 在首次定位「全局素材」页签时超时。该页签在 `3b9506c5e` 统一素材库侧栏时已移除。当前侧栏和项目范围由 `test:library:navigation` 验证。
