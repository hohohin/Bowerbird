## 2026-10-19 Cloud 优先复用已有标签

Cloud 仍仅在 Jev 没有真实标签达到 30% 或启用词表为空时介入，但先按完整边界定义复核已有标签。每次实际发起 Cloud 请求前重新读取当前完整词表（含 ID、名称、完整说明、启停），覆盖排队期间其他 Cloud 任务新增的类别；停用标签只用于防止换名重建，不可自动挂载。

- 返回三种互斥结果：`matched` 携带 1–4 个已有标签 ID；`new_label` 携带单个类别；`undetermined` 对应「无法判断」，不创建标签。已有匹配直接保存，不再要求它达到前序 Jev 门槛；人工排除/修订保护保持。
- 用户提供的全部新增约束已写入提示词：不同具体对象/颜色/风格/材质/背景/细节、多个已有类别同时适用或数量限制均不构成新增理由。不得新增同义改写、修饰词细分、宽泛总称、类别拼接或无关信息；优先常见 2–8 字名词类别。
- 新类别必须有 `name`、`definition`、`exclusion`、`reason`。可见特征和排除情况合并写入标签说明（总长 ≤600 字），最接近已有类别及不足的理由单独保存到图片观察记录 `description`，不污染可复用边界。看不清/类型不确定返回「无法判断」。
- 本地结构校验拒绝未知或停用 ID、同时匹配又新增、多新类别、同名新增、缺少特征/排除/理由、超长内容，以及把「无法判断」或「无明显匹配项」作为新标签。语义同义和边界合理性仍由模型按完整词表判断，不能用结构测试代表真实准确率。
- 原 Jev 排名、Cloud 并发/认证/计费、取消、同名并发保存复用、文件夹隔离及旧观察记录免自动重扫保持；不迁移/清理已有标签，不操作真实素材库，无服务端部署。

## 使用与边界

侧栏「分类标签 → 管理」打开本地分类面板。首次下载 Windows 约 756 MB、Mac 约 749 MB，Windows NVIDIA GPU 加速另需约 645 MB；可先手动「识别未处理素材」，也可打开自动处理。自动开关会扫描当前库中尚未识别的图片，并处理已排队的新增/修改标签；每 15 秒检查一次。关闭面板不终止后台任务，“停止”也关闭自动处理，已完成结果保留；下载重试复用完整且通过校验的文件，未完成的单文件重新下载。无法补齐的分类错误会暂停自动处理，原因在面板保留。

标签名称/说明可编辑，停用后不参与自动匹配但保留已有归属。开启自动处理时保存标签会排队匹配存量；未开启时用「保存并寻找匹配素材」。选中素材后可明确添加正例或排除；单次上下文取至多两个手动正例和一个反例，自动及历史来源不作为训练示例。重新扫描只撤销本地模型自己的、不再匹配的归属，不删除人工或历史标签。

此版本是单 VLM 的动态标签基线加可选向量匹配判官，不含向量聚类/相似搜索或模型微调。发现阶段参考按素材确定性抽样的最多八个已有标签名（仅用于统一命名，不按引用次数排序）；自动匹配只作用于设过人工示例的标签，无示例标签仅由用户显式「寻找匹配」判断整库；**安装向量包（jina-clip-v2 int8，约 881 MB，macOS Apple Silicon / Windows x64）后匹配判断改用余弦相似度，未安装或加载失败回退 VLM 判断，Intel Mac 暂无向量包**；可选的 Jev 云端校验默认关闭，启用后仅出机文字描述与标签文本。语义近义词合并依赖模型复用名称，尚无独立的语义去重索引。模型包保存在应用数据目录 `local-classification/qwen35-08b-b10809-v1`（向量包在其 `vector/` 子目录），识别记录/标签/纠正在当前库 SQLite 中，与反推 caption 分离。

后续质量验收：用用户实际素材建立独立标注集，测标签精确率、覆盖率、风格区分、近义标签膨胀及 CPU 耗时/内存；若 0.8B 无法达到要求，再对照更大模型或专用向量匹配模型。未发布、未部署 Cloud、未进行付费模型调用。

## macOS 模型下载与系统代理（2026-09-17）

用户在安装版中点击下载后收到 Hugging Face `error sending request`。本机复现：系统 HTTP/HTTPS 代理已启用，直连模型地址被 reset，经系统所配置代理可以获取文件。根因为 reqwest 配置 `default-features=false` 后遗漏 `system-proxy`，Finder 启动又不继承终端代理环境变量；之前手动 curl 下载缓存的测试未覆盖此入口。

Mac target 现显式启用 reqwest `system-proxy`，因此该平台默认 HTTP 客户端读取系统 HTTP/HTTPS 代理；Windows 特性不变。本地分类推理客户端仍显式 `.no_proxy()`，图片请求只走回环地址。下载错误保留底层原因，移除错误 URL（避免显示 CDN 签名查询参数），提示检查网络与系统代理。未增加第三方镜像或固定代理端口，不改变固定版本、大小及 SHA256 校验。

本机即时恢复：确认应用模型目录为空后，将前次隔离测试留存的模型、视觉投影和 Intel 运行时复制到临时目录，逐文件复核固定 SHA256，解压并实际运行 `llama-server --version`，最后写入安装标记。现有安装版可直接使用模型；未访问素材数据库、未开启自动分类。该恢复不等于现有二进制已包含新的代理修复。

## 批量标签重复判断修复（2026-09-17）
