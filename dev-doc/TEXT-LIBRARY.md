## 放大编辑与画板文本卡片（2026-11-03）

- 创作框与历史生成的继续编辑框右上角增加放大入口，懒加载共用 `TextWorkspace`／Plate。左侧直接复用画布的分类／集合、全局／项目、搜索、媒体筛选、分页、常用素材与宽度控件及其样式；浏览与宽度状态独立。单击预览，双击或 Enter 将图片／音频／视频插入原光标处；文本素材打开详情。Tab 只移动焦点，不打开素材库或切换视图；放大工作区仅显示正文，原素材详情保留正文／源码切换。
- 素材右键菜单、集合操作、详情与预览保留在文本工作区内部，关闭子窗口不退出编辑器；显式标注、分层、回看创作等跳转先保留草稿并退出编辑器。嵌入入口不借用背景画布的详情选择或全局选图事件。异步插入仍以 Slate 选区书签保持光标位置。复用专项的回归与质量证据见 [行动记录](../project_logs/2026-11-03-text-workspace-library.md)。
- 返回、重命名、文字格式和三个动作合并在右侧编辑器顶部的工具栏，删除独立顶部栏；素材库默认展开，左右两栏均占满高度。素材库与整个右侧面板以同步 260ms 过渡展开／收起，减少动态设置下取消可见动效。关闭／拖动标签随工具栏实际高度向下避让。
- 工具栏右侧三个动作：保存到集合、保存到项目、添加到生成对话框。集合写入所选已连接目录中的新 `.md`，不覆盖同名文件；项目创建一个原生文本卡片，不另存第二份可编辑文件。新建命令只接收集合／项目身份，不接受任意写入路径。
- 保存以冻结内容、标题和目标映射请求身份，关闭后重开重试沿用该身份；原生回执支持中断恢复，已完成的重试不覆盖后续编辑，也不复活已删除卡片。保存中继续输入留在当前草稿。
- 创作框来源的编辑草稿按输入来源及当前会话保留，返回仅关闭；点击添加才回填，保留 Markdown、原素材身份及已有画板实例定位。无编辑回填保持原 ProseMirror 节点。素材缺失、原输入已变化或回填期间继续编辑时拒绝旧结果；关闭／切项目后的迟到回包不修改另一输入。仅填草稿，不发送或运行模型。
- 画板工具栏新增文本卡片，支持放置、移动和放大编辑；固定 56px 标题条，不再显示正文预览或高度缩放，空正文显示“空白文档”。`note_type:"document"` 以 `text` 为唯一 Markdown 正文，`cells:[]`；旧二维内容卡不变。编辑沿现有画板写入队列保存，返回／切换前冲刷，失败沿画板保存重试恢复。
- 两个输出：图片口只交付文档中的图片；文本口按顺序保留 Markdown 与受控媒体引用。统一生成引用仍沿现有 `@图片N` 协议（含音／视频附件），实际媒体支持由下游模型校验。路径溯源不进入模型提示词。代码围栏、frontmatter、缩进代码与连续原始 HTML 示例不登记为附件；项目删除保护使用相同独立媒体块边界。

验证入口：`document-projection.test.mjs`、`document-composer.test.mjs`、`canvas-document.test.mjs`；正式组件 `text-workspace-live-ui.test.mjs`、`text-composer-entry-ui.test.mjs`、`canvas-document-ui.test.mjs`；原生创建／恢复 10 项、原文本 10 项及文档卡协议 3 项。完整 TypeScript 与独立 Vite 构建通过。所有测试使用合成 IPC 或临时文件／数据库，无真实生成或用户库写入；前后端需配套重建，未发布安装包、未验收 Mac 原生。质量工具与行动记录见 [本轮日志](../project_logs/2026-11-03-text-workspace.md)。

## 文档内 Agent（2026-11-03）

- 放大工作区只在光标所在段落的把手左侧显示 Agent。气泡复用 `ModelSelect` 的 Provider／自有额度／Bcoin 菜单，嵌入菜单使用工作区的浮层与焦点边界。
- 本机沿用 `agent_ds_workflow_start` 的 Codex CLI 通道，每次请求使用隔离会话，仅显式传入当前段落和本气泡历史。Cloud 沿用统一 DSH 的 `textRewrite`／`text.result` 契约，关联真实项目与新建创作线程；无项目时沿用素材库创作项目准备入口。没有新增 runner，也没有使用 DeepSeek 普通聊天代替 DSH。Cloud DSH 仍限服务端授权的测试账号，BYO／并发策略保持。
- 回写接口为任务结果中的 Markdown 文本，使用 Plate 变换插入发起段落之后，连续对话从上一轮插入末段继续。输出可撤销；以节点 ID 和发送快照校验锚点，段落改动或删除时保留回复，并提供“插入到光标处”，不覆盖手工内容。当前正文＋气泡历史沿既有 16000 字输入上限，回复亦为 16000 字上限；不额外传全文或素材原件。
- 读取异常保留原请求“继续取回”，不重复提交；停止、关闭气泡、切换到另一段落气泡、关闭工作区都会使迟到结果失效并尝试取消。取消失败保留可见提示。气泡历史为当前打开期间的会话状态，关闭后新开；已写入正文按原草稿／保存流程持久化。
- `text-agent-ui.test.mjs` 覆盖两通道、额度菜单、连续对话、Markdown／撤销、并发修改／删除、错误请求身份、失败／非文本 Cloud 结果、原请求取回、停止与关闭竞态、账号变化；布局、段落操作与原文本详情回归、TypeScript 和独立 Vite 构建通过。使用合成 IPC，无真实模型调用／扣费；Cloud 服务和本机 CLI 的真实运行验收未纳入。本轮行动与质量证据见 [日志](../project_logs/2026-11-03-text-agent.md)。

## 接入范围

- `.md`、`.markdown`、`.txt` 复用「建立连接」及文件夹扫描，登记原路径，不复制已有文件。
- 现有素材库类型控件增加文本，沿用全部、标签、集合、搜索、分页、分栏和轻量卡片。卡片只读索引元数据，打开详情才加载 Plate 和正文。
- 编辑器在原 `AssetDetail` 媒体舞台内，原顶部栏、侧栏和右侧资料区不改布局。文本不显示图像反推／再创作，也不能作为画板图片或模型图片参考。
- Markdown 有正文／源码、标题、粗体、斜体、简单列表、引用、撤销／重做；TXT 按字面编辑。显式保存或 Ctrl/⌘+S 写回原文件。
- 文档内可插入已有图片、音频、视频引用；移除文档中的块只修改文档。原素材详情的转发入口仍未新增；本次创作框／画板入口见上节。

## 原件与草稿

入口：`core/text_documents.rs`、`commands/text_documents.rs`、`TextDocumentEditor.tsx`。

`read_text_document(assetId)` 和 `save_text_document(assetId, expectedVersion, text)` 返回 `{ assetId, path, text, version, format }`。命令只接受登记的素材身份，读取 `assets.store_path`，不提供任意路径写入。磁盘工作在线程池执行。

- 暂支持最多 2 MiB 的 UTF-8（含 BOM），其他编码、二进制、只读、失联或超大文件清晰报错。
- 版本为文件内容 SHA-256。保存先核对打开版本，同一路径的应用内保存串行；准备替换文件后再次核对版本及登记路径，发现外部变化拒绝覆盖。
- 在原目录写临时文件并同步后原子替换，再刷新原素材索引、广播更新；标签和身份保持。索引刷新失败明确区分「原件已保存，索引待刷新」。没有与任意外部进程协作的文件事务，不宣称能消除校验和替换之间的所有系统级竞争。
- 保留 UTF-8 BOM、常规 LF/CRLF、系统基本权限；无变化保存不改混合换行。编辑后混合换行按原件是否含 CRLF 统一。未验证扩展 ACL、扩展属性或网络文件系统替换语义。
- 草稿以素材 ID 和原路径分开保存在当前应用会话的内存及 sessionStorage；内存是存储失败后的兜底，并显示先保存再退出提示。应用退出尝试提示未保存，不承诺进程崩溃／彻底退出后恢复。
- 保存回包合并共享最新草稿，保存期间继续输入、离开再打开和旧回包乱序均不会覆盖新输入。重新读取原件丢弃未保存草稿前确认；读取期间已继续编辑则忽略旧读取回包。

## Markdown 与媒体

使用 MIT 的 Plate 53.5.2 与所选基础、列表、Markdown、媒体插件，不使用 Plate Plus 模板。锁定版本见 `apps/desktop/package.json` 与根锁文件；许可文本随 `apps/desktop/public/licenses/text-editor.txt` 进入前端构建产物。

媒体保存为受控引用，例如：

```html
<img data-bowerbird-asset="ID" data-caption="URL编码说明" data-source="URL编码原路径" />
```

`audio`、`video` 使用同一属性协议。原路径是溯源信息；当前仅解析已经登记的 ID，不依据文档内容自动读取或登记任意本机路径。文件导入通过现有原位连接 API，图片按需显示、音频复用共享波形播放器、视频 `preload="none"`。当前同库重新打开可恢复引用，不宣称跨设备 ID 恢复已完成。

不执行 HTML/MDX 或自动请求外部媒体。外部图片、链接、表格、代码、任务列表、frontmatter、复杂列表等本轮未支持的语法保留为字面源码块，亦可在源码模式直接修改。禁止剪贴板媒体自动转成无来源附件；普通图片 URL 仍是文字。正文编辑可能规范化 Markdown 的空行、强调符号与软换行空白，不宣称字节级无损；仅打开或切模式不会自动写原件。
