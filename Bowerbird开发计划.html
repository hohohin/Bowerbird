02 技术栈选型

决策点已定：React / WASM 插件 / 2–3 人。v1.2 删除所有自建 AI 依赖。

Rust 后端 Crates（v1.2 精简）

用途Crate
异步运行时 / 子进程tokio（含 tokio::process 管理 codex 子进程）
SQLite / 迁移rusqlite(FTS5) / rusqlite_migration
图像解码缩放image + fast_image_resize
多格式psd / resvg / rawloader / ffmpeg-next
颜色 / 去重自实现 K-Means + palette / img_hash（pHash 去重）
codex 调用 NEWtokio::process::Command + serde_json（调 claude -p，解析 JSON/流式）
WS / 监听 / 基础axum / notify / tracing / serde / thiserror

移除：ort、candle、mistralrs、tesseract-rs、sqlite-vec（无本地 AI、无向量）。

my-library/ ├── library.db # SQLite：元数据/标签/提示词/索引/分析/任务 ├── .bowerbird/ │ ├── config.json # 含 codex provider 设置 │ └── thumbnails/ # JPEG 缩略图（hash 分桶） ├── images/ # 原始素材（不修改） └── exports/ # .bowerpack 导出包 # v1.2 移除：models/（无本地模型）、generated/（不做生成）

核心表

CREATE TABLE assets (id, name, ext, origin_path, thumb_path, size, w, h,
  phash,           -- 仅采集去重
  colors, rating, source, source_url, folder_id, ...);

-- ============ 提示词体系（核心新增）============
CREATE TABLE prompts (
  id, title, body TEXT,           -- 提示词正文（FTS5 主体）
  kind DEFAULT 'manual',          -- manual | generated | template
  source_model, created_at, updated_at);
CREATE TABLE asset_prompts (
  asset_id, prompt_id,
  role DEFAULT 'ref',           -- main(主提示词) | ref | desc
  PK(asset_id, prompt_id));

-- 全文检索（含提示词正文）
CREATE VIRTUAL TABLE library_fts USING fts5(
  name, tags, prompt_body, annotation, ocr, tokenize='trigram');

-- ⑤ 拆解分析结果（codex 产出）
CREATE TABLE analyses (id, asset_id, kind, payload JSON, provider, created_at);
  -- kind: caption | keywords | ocr | layout | inspiration_card
