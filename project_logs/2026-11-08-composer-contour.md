用户确认「轮廓光膜比较好，可实装」。沿用 UB Mode，先查现行约定、视觉规范和复用地图；素材库与项目画板已有共用 `ComposerProjection`，本轮只接入确认材质，不改编辑器、素材引用、模式草稿、项目归属或生成链路。

## 实现

- 先用本机 Chromium 验证 SVG 卷积可直接作用于真实 backdrop。正式实现读取页面后景，不像独立示意页那样另铺图片副本，也不读取素材原件或增加请求。
- 在 `ComposerProjection.tsx` 定义深浅色滤镜，以灰度、3×3 拉普拉斯边缘与通道映射保留细轮廓。按确认稿 72% 细节混合折算系数：深色 `.1584/.1728/.1872`、浅色 `-.1656/-.1584/-.144`；基底对应深色石墨蓝灰／浅色银灰。每个实例的 filter ID 由 React `useId` 生成，避免两个入口相互引用。
- `IndustrialCanvas.css` 将表面 14.4px 模糊替换为轮廓滤镜，加入 24% 斜向微眩光。沿用上弧线、侧向羽化和底边覆盖；正文、输入与按钮不加入滤镜。保留白色悬浮标签、呼吸方点、三层小叉、轻闪与鼠标视差，收起态使用同一静态材质。
- 减少透明效果时移除滤镜与眩光，使用不透明主题阅读面；高对比模式保留系统色。CSS 不支持 backdrop URL 时提供主题底色退化。SVG backdrop 的 Mac WebKit 实际渲染尚未验证，不能把 Chromium 结果视为 Mac 验收。
