### 路线与完成信号

| 身份 | 实操路径 |
| --- | --- |
| 设计师 | 主界面点击新建创作 → 导入「初始引导」文件夹 → 聚光画板素材库，阅读项目/全局素材归属 → 点击探索 → 关闭小红书登录框（如有），拖图采集到画板 → 展开素材库 → 点击对话框激活创作模式 → 左键点击有预置反推数据的示例图，打开维度环 → 点击「反推提示词」维度加入对话框 → 画板整体聚光，完成本次引导后展开主左栏并指向登录区域。当前共十步 |
| 市场运营 | 认识界面 → 导入图片 → 打开有素材的品牌集合 → 保存该集合的视觉规范 → 在创作中主动选用刚保存的规范 → 使用该规范生成至少两张营销图片，可分多次生成 |
| 视频编导 | 认识界面 → 导入图片 → 在真实创作输入中分行编写分镜脚本 → 根据脚本生成分镜表图片 → 切换视频，准备镜头要求及参考并取得视频结果 |

- 设计师身份卡仅退出到主界面，不创建项目；用户点击「新建创作」后创建「设计师 · 入门创作」，沿已有命名项目写入屏障持久化。其他身份保持首次点击创建独立实操项目。恢复返回原步骤与项目；尚未新建时返回主界面。原项目被删除时明确报错并提供重新开始入口，不删除其他项目或素材。
- 设计师新建、文件夹导入、打开探索、采集落板、点击对话框激活创作模式后自动推进；素材归属说明和素材库展开后由用户点「下一步」，打开示例图片维度环后自动进入第九步；选入反推提示词后在同一步聚光对话框并说明已添加，用户再进入完成页。其他身份保持原有任务清单；认识界面可阅读确认，实操步骤必须取得成功信号。取消选择、错误文件夹、空导入、异常、失败任务不算操作完成；用户可主动「跳过此步」继续。
- 设计师导入步骤复用 `release_preset_pack`，释放随包素材到文档目录 `Bowerbird/初始引导`，文件夹选择器打开其父目录，只接受该文件夹成功导入；不再要求单独导入图片。导入后自动显示项目素材页签，说明文字采用用户原文，追加「全局素材包含项目素材」。
- 导入、采集、标注、反推队列、集合读取、规范保存与规范选择在现有成功路径上记录完成。回调冻结原身份、项目、步骤、本次实操标识及步骤访问次数 stepVisit，迟到结果不能推进另一身份或重新开始的路线。规范保存及选择还核对集合与规范 ID。
- 普通图片/视频结果按项目和本步任务轮次计数，运行中、错误、旧历史、其他项目和错误媒体类型不计入。参与任务的轮次索引持久化，支持暂停/重启后继续核对返回结果。营销图片还核对所选规范。
- 真实分析和生成仍由用户主动确认服务、用量并发送；教程不会替用户发起调用。脚本步骤只检测新输入的多行文字；分镜表的视觉质量仍由用户判断。
- 设计师使用 SVG 遮罩挖空的 spotlight 与相邻说明卡；聚光区域和控件框选独立定位。导入菜单打开时聚光整个菜单，单独框选「导入文件夹」；第三步聚光画板素材库并框选素材来源区域（保持项目页签）；第六步聚光整个项目画板，单独框选素材库展开/收起按钮，采集归属说明首句后换行。其他步骤不恢复之前大面积的蓝框。提示卡跟随窗口尺寸与布局更新，可收起、暂停、切换身份和跳过；登录、设置等应用模态窗口出现时避让。
- 探索首次打开默认小红书，设计师进入探索步骤时明确导航到小红书；普通关闭/重开保留网页实例与浏览位置。第五步在真实网页旁给出关闭登录框的文字，并在画板侧说明卡里播放虚拟鼠标+虚线拖图动画（支持 reduced-motion）。不读取第三方登录状态，不伪造检测登录框关闭；必须真实采集并保存画板卡片才推进。动画卡避开原生 WebView2 与右上角通知；重启到采集步骤时提供重新打开探索按钮。其他区域聚光时，SourceBrowserPanel 将 dimmed 状态随 resize_source_browser 同步给原生网页；网页内顶层遮罩与主界面使用同样的 .56 黑色透明度，暂停、收起或退出聚光即移除，不隐藏网页、不刷新。网页加载完成时恢复当前遮罩状态；采集步骤保持可见可拖动。
- 第七步聚光真实对话框，文案「点击对话框激活创作模式」，由现有对话框 focus 操作激活并确认成功。第八步查询该项目的现有反推数据，优先定位 origin_path 中的 preset-01（护发产品示例），可回退到同包其他已带维度的收集图；不把任意用户图片当示例、不触发反推服务。素材来源自动展开到项目范围并滚到目标；左键点击走现有素材拾取与维度环，环内实际出现维度才算完成。说明按用户文案分行并加粗「反推」。若跳过导入或图已不在项目中，提示补导入后重新查找或跳过。引导卡 portal 到 body，环打开时避让其范围并置于环遮罩上，保持可读、可点击。
- 第八步实点开环即自动进入第九步，无需点下一步或再次点图。第九步在维度环上层直接聚光并框选「反推提示词」扇区；检测到对话框里属于该示例的对应词条后，收起维度环，聚光真实对话框，说明「所选的「反推提示词」维度已经添加到了对话框。你可以继续补充创作需求。」再解锁下一步；选择其他维度不计完成。第十步聚光整个项目画板，展示「恭喜你，现在你已经准备好生成了！开始筑巢吧」、品牌图标与「完成本次引导」。完成后关闭探索以避开原生网页，展开主左栏，气泡指向账号区，内容「登陆以使用园丁鸟创作功能」，点击打开既有登录面板；完成气泡不再因已登录状态被直接关闭，用户可主动关闭。其他身份仍可由入门入口继续。
- 说明卡正文 12→16px、标题 18→22px，设计师标准宽度 320→416px，其他路线 292→380px，内边距同步放大；窄窗口仍受可用区域约束。顶部左箭头「上一步」、右箭头「跳过此步」，首步左箭头禁用。回退保持项目及实际产物，reviewUntil 记录回看边界，回看步骤不自动跳转，可手动下一步；回到首步和暂停恢复均返回主界面，再继续复用原项目。维度环不会因鼠标移入引导卡而自动关闭。「继续入门引导」气泡 portal 到 body，固定在应用右上角，位置随 Status 按钮下缘变化；登录及恢复提示的模态遮挡检测独立于路线完成状态。
- 每个身份每一步（包括首步、末步）都提供顶部右箭头「跳过此步」，与退出整个教程的「跳过入门引导」分开。跳步保存 skippedSteps，不伪造操作 ready，完成卡明确标注含跳过步骤；重启保留记录。跳过创建时不代建项目，后续可通过新建创作绑定项目，或继续跳步；过期操作回调不能完成下一步。
- 路线完成页提供其他身份；三条实操全部完成才记总完成。跳过只退出引导，保留项目、草稿和未完成进度。暂停保存失败会提示，跳过不依赖保存成功，迟到暂停不能重新打开已跳过的浮层。

### 入口与主线

- 首屏与设置入口现统一进入上面的身份选择；历史「新版变化」面板仍保留，首启不再以是否空库分流。
- 示例实操页提供示例、自己的图片、继续上次实操进度、返回身份路线与跳过入口。
- 示例创建独立的「我的第一次创作」空白项目。两张随包图片分别是护发产品和蓝色配色参考，附带已有维度；用户自己拖入画板。
- 主线是普通图片生成：拖图 → 移动卡片 → 写目标并加入参考 → 借用维度 → 主动发送并等待实际结果，取得结果后点击「完成入门引导」。已按用户要求删除「从结果继续修改」，主线共五步。视频和 Agent 执行不作为本轮主线的完成信号。
- 右上角是可收起的任务清单，只描边相关控件；保留正常页面交互、维度环关闭手势。打开登录、设置等模态窗口时立即隐藏清单和暂停后的恢复气泡，关闭窗口后恢复；引导浮层层级低于模态遮罩。
- 欢迎页、展开/收起的任务清单和恢复气泡均提供「跳过入门引导」。欢迎页关闭也视为跳过；跳过立即移除浮层并持久保存 skipped，不清空项目、草稿或步骤，不依赖画板保存成功。恢复气泡右侧的关闭按钮执行跳过；以后可从设置重新打开并继续原进度。已完成状态不会被跳过改写。
- 第四步可明确跳过维度，清单显示「已跳过」。第五步可「先完成准备，稍后生成」，记录 prepared 与 paused，不宣称已经生成或整课完成。

### 数据与恢复

`lib/onboarding.ts` 定义 v2 进度与纯推进判断；`lib/onboardingStore.ts` 独立保存 `bowerbird.onboarding.v2`。记录项目、示例项目、开始时间、生成任务、步骤、完成类型、升级页已读和专题提示关闭状态。重启后 active 恢复为 paused，错误或未知版本数据回到初始状态。

`OnboardingTour.tsx` 只在学习期间检查当前已加载的项目画板和真实编辑器内容；其他项目、没有结果的失败任务、旧任务不会推进生成步骤。移动卡片以位置变化判断，加入参考与维度以编辑器实际内容判断。旧版停在第六步的用户恢复到第五步，保留项目与任务标识；已经完成的状态不清空。

暂停前调用画板现有 flush；失败时保留当前学习状态并显示保存错误。恢复先检查项目仍存在，路由切换沿用既有保存协议。示例准备过程中用户已切换页面时，保留新项目并提示重新进入，避免迟到请求抢走当前页面。

后端 `commands/preset.rs::create_onboarding_project`：

- 直接读取随包 `PRESET_SPECS` 的前两张图；不经过会自动分析的文件夹导入流程，不启动模型或要求账号。
- 复制为新的 imported 资产，名称带「示例」，维度分析标记 `bundled-example`。不覆盖去重命中的用户资产，不伪装生成结果，并清除指向安装资源的 `origin_path`。
- 使用 `onboarding:v2:{projectId}` 来源标记保护示例身份。重复打开同一个示例项目不重复导入、不重置用户编辑；用户删掉的素材也不自动补回。
- 资源缺失时明确报错；与已有普通项目的标识冲突时拒绝修改。部分导入失败时移除失败项目关系，保留已入库资产，重试可能留下额外示例副本。
- 注册新 Tauri 命令，因此仅刷新旧桌面进程前端不足以使用新示例入口，需要重新构建/启动对应后端。

### 按需提示

欢迎页和完成页提供显著的「学习集合与视觉规范」入口。集合教程单独解释四件事：按品牌/主题命名、添加或导入图片、主动提炼、保存后显式选择规范；可以直接创建集合或打开已有集合。集合面板内也有同一份可收起/重开的教程，空集合首次默认展开。已有素材加入集合会改变素材库归属，不改变已有关联画板布局。提炼仍可跳过，不自动调用模型。

集合创建复用 UI「集合」的普通 folder API，不能误用对应收藏夹的 kind=collection。创建成功、随后刷新失败时保留新 ID，重试打开而非再建一份；侧栏折叠时也可打开集合面板。进入集合教程前保存当前草稿并暂停进行中的画板主线。欢迎页另外保留探索、反推维度、视觉规范、本地分类、画板整理五个折叠主题，其他页面的短提示在主线激活时隐藏。

探索提示放在右侧工作区的正常布局中，避免遮挡素材栏开关；原生网页区仍由既有浏览器组件管理。说明明确网页拖图当前适用于 Windows。视觉规范沿集合提炼、保存后主动选择；本地分类说明首次约 756 MB 下载与本机推理，不将分类标签和反推维度混用。
