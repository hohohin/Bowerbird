# 文本素材与内置编辑器实装

## 已确认范围

用户认可 Plate 能力，但要求只实装文本导入与编辑器，不改变现有布局。本轮复用现有素材类型控件、卡片与详情舞台；不接预览中的左栏/整页布局、转发或模型调用。已有文件原位连接，保存显式写回原件。此前仅本地提交、不推送的约定保持。

## 行动

1. 按 ub-mode 阅读现行项目、文件连接与音频接入约定，检查共享工作区并备份已有 PROJECT/CanvasWorkspace/types 供部分提交核对；不改其他任务代码。
2. 并行分工原生文本索引/安全读写、正式 Plate 编辑器与媒资引用、现有卡片/筛选与类型保护；主线程整合现有 AssetDetail 和跨模块验证。
3. 正式组件隔离测试先证明详情没有文本编辑器（实际超时 RED），再在原媒体舞台接入 lazy Plate，保留详情头部和右侧信息/标签。文本不进入图像预览、反推和再创作控件。
4. 后端以注册素材身份定位原件，文本索引只计算文件身份；明确跳过图片解码、提色及自动分析。读写加 2 MiB/UTF-8 边界、内容指纹冲突检查、同路径保存串行、同目录原子替换、索引刷新；10 项临时文件／数据库测试验证实际磁盘行为。无变化混合换行保存曾真实失败，修正后通过。
5. 现有全部／标签／集合与分栏接入轻量文本卡片和文本类型，保持分页／虚拟网格；画板及图片模型入口增加文本类型保护。未改整个画板交互或现有创作输入。
6. 接入真实 Plate 正文与源码、TXT、原文件媒体引用；使用现有波形播放器。草稿按文件分开；修复旧保存回包覆盖重开编辑器新草稿的竞态，加入共享保存完成同步及读取代次检查。
7. 独立只读审查复现粘贴图片 URL 丢原地址、普通 Markdown 软换行改成硬换行，两项新增回归先 RED 后修复。拒绝无原件的剪贴板媒体自动嵌入；外部源码不执行或发请求。编码恢复提示的 UTF/Markdown 白名单亦先 RED 后修正。
8. Chromium 验证正式素材库、详情及编辑器。第一次扩展测试因 PlateElement 不透传自定义 data 属性而失败，DOM 确认正文正常，改用真实 class 选择器后通过；未改产品迎合错误选择器。补充保存中退出／重开并继续编辑、三类媒体引用、纯文本和浅深窄宽布局。
9. 更新 PROJECT 有效决定与 TEXT-LIBRARY 技术边界；核对本次新依赖的 MIT 等许可并随 public 资源保留许可文本。存档只暂存本轮文件，CanvasWorkspace/PROJECT 用限定补丁排除共享工作区的其他任务修改。未推送。
