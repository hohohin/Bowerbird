# 角色声音：交互确认稿

2026-11-10。当前交付为独立网页原型，等待用户确认交互后再修改正式应用。

## 打开

在仓库根目录运行：

```powershell
node dev-doc/ui-studies/voice-studio-2026-11-10/server.mjs
```

打开 <http://127.0.0.1:18026/>。服务只监听本机，白名单只开放原型文件及两个既有试听样本。

## 评审路径

1. 首次使用：启用本机配音 → 自动检测与准备 → 可关闭窗口、暂停或继续。
2. 用录音创建：选择文件／素材库 → 选择片段 → 原声与新声音对比试听 → 命名并保存。
3. 用文字创建：描述声音 → 试听 → 命名并保存。
4. 日常配音：选择声音 → 输入台词 → 生成 → 试听、再生成一版、加入画板或导出。
5. 顶部场景切换器：下载中断、保存失败、设备不支持。它属于评审工具，不进入正式应用。

布局复用应用工业制图主题的深浅色、细边框及弱强调色。技术路径收进安装详情；日常操作围绕“我的声音”和台词展开。声音创建窗口关闭后保留草稿，配音可取消，保存失败只重试保存。

## 模拟边界

- 设备检测、安装、生成、素材库、画板和保存均为模拟；不下载模型、不调用 VoxCPM、不写真实项目。
- 试听播放已有测试样本，不能据此评价本次输入的文字描述或上传录音的生成效果。页面持续标注这一点。
- 两个音频直接读取被忽略的 `.tmp/voxcpm-local/user-reference/reference.wav` 与 `.tmp/voxcpm-local/user-clone-output/01-clone.wav`，不纳入源码。其他电脑需要自行准备样本；缺少时仍能评审交互。
- 用户选择的文件只通过浏览器对象 URL 试听，不上传。刷新后重新选择本机文件才能继续试听原录音。
- 原型状态保存在浏览器 `bowerbird-voice-review-v1` 中。顶部“重置示意”只清理本原型数据。场景切换会重置模拟状态。
- 波形为示意，不是音频分析结果。导出文件明确命名为历史试听样本。
