# 文本编辑器完整 Demo 接入

状态：实现与隔离验收完成，源码未发布。用户确认评论、修订、@提及只在本机文档使用，不要求跨账号多人协作。

## 实现与核对记录

1. 阅读 PROJECT、文本专项、UI 规范、复用地图及 Agent / provider 契约；核对现有工作区、素材库、生成草稿、原文件保存入口。保留公共入口，删除被完整 EditorKit 替代的四个旧组件。
2. 先复现底部空白点击问题，再实现新增或聚焦空尾段落。处理正文末尾、标题、图片、空文档、连续点击和撤销；捕获阶段清除块多选，避免 Slate 默认点击处理抢走新光标。
3. 核对 Plate 官网开源 EditorKit registry，递归复用公开 MIT 组件及 Excalidraw；保留 kit / UI / primitives 组织，记录原始 registry 哈希。未复制示例服务端、模拟 AI 或 UploadThing。
4. 安装锁定版本依赖；适配 React 18 ref、日期／文件选择器和 AI SDK 7。Tailwind 4 只编译带编辑器作用域的 utilities；处理与应用 Tailwind 3 的 transform 和 CSS layer 冲突。移除未使用的 sonner。
5. 完整组件接入 TextPlateEditor，保留素材插入书签、提示词复用、段落 Agent、右侧工具栏、默认展开素材库和三个保存／添加动作。工具栏换行高度参与侧栏标签避让，保存菜单层级高于格式工具栏。
6. 文档采用可读 Markdown + 校验正文指纹的富状态尾注；讨论日期和富内容恢复，校验非法树／深度／数量，清除临时媒体 URL。修复 CRLF 尾注识别，前端与 Rust 使用同一含中文／astral 字符夹具；投影及 Agent 不携带内部尾注。
7. 媒体复用应用导入和素材身份，修复文件选择器相对路径被误认为本机原路径；Plate 节点保持对象身份，URL 在实际节点上补全。音频复用 AudioWaveform，本机视频不预加载。附件按内容哈希落盘，限制 50 MiB、校验路径并原子写入。
8. 接入本机评论／回复／解决状态、修订和自定义提及。修复第一次添加讨论时换包裹 DOM 导致 Slate 节点定位错误；保留稳定结构。
9. 工具栏 Agent 复用 TextAgentTask、Codex CLI / Cloud DSH 与模型／Bcoin 菜单。实现选择改写、评论、所选表格改写、接受／舍弃、原请求取回和取消重试；并发修改转为预览，表格尺寸不匹配保留原表。修复单元格内气泡过窄。
10. 导入 Markdown / HTML / Word，导出 Markdown / HTML / PNG / PDF / Word。静态渲染嵌入媒体与公式字体，绘图导出图像；修复 iframe 销毁后 canvas.toBlob 无法完成。DOCX 所需 Node polyfill 限于浏览器依赖适配。
11. Excalidraw 字体本地提供；Mermaid / Graphviz / Flowchart 本地渲染。PlantUML 在线预览必须由用户点击，打开文档不自动发出图表请求。
12. 逐项操作中修复字号旧选区／弹层夺焦、引用切回正文、浮动工具栏滚动跟随及 Alt+F10 / Escape 导航、段落操作残留块选择、表格合并后不能拆分。表格根因是 Plate 53.0.9 的单单元格过滤，使用公开 API 补充 canSplit。
13. 回归原文件编辑：将旧的禁止外部图片断言更新为当前完整编辑器行为，并用真实剪贴板事件测试；合成 ClipboardEvent 会被 Slate 忽略，不能用它判断粘贴是否可用。保存冲突、保存期间输入、关闭重开及三类媒体引用通过。
14. 清理旧工具栏、块拖动和输入规则实现及孤立样式；更新专项、复用地图和项目约定。新增依赖许可随 public/licenses/text-editor.txt 分发；registry 原件哈希见 plate/provenance.json。

## ub-mode 质量检查

- Crapper：应用适配与数据边界的实际 V8 覆盖率转换为 LCOV；检查函数最高 CRAP 9.5，均小于 10。跨页面覆盖率逐页收集，避免只保留最后一页。
- Dryer：同一适配范围无 0.8 以上重复候选；讨论基础字段校验已统一。
- Mutator：隔离副本 76 个变异，74 killed，2 survived。存活项仅改变 record 的前置对象类型判断；非法输入仍被后续块／讨论结构校验拒绝或进入同一解析失败分支，公开读取结果等价。没有遗漏的行为变异。深度 128、数量 100000、无 ID 评论、固定指纹与富格式形状补充测试后通过。
- 上游组件保留其组织与行为，没有为指标重写整个第三方组件库。未把上游代码全量复杂度、覆盖率或变异测试声称为本次通过范围。
- 可复核产物位于 .tmp/text-editor-demo-quality 和 apps/desktop/.tmp/text-editor-*；不提交浏览器缓存、测试副本或截图。
