# 2026-11-03 生成框 HUD 与景深

## 目标与复用

用户要求生成对话框更接近极简全息 HUD／电影式景深，主屏未激活时贴底，展开使用相同风格动效。采用已调用的 UI UX Pro、ub-mode；当前产品约定记入 PROJECT.md。

先查复用地图、现行 UI 规范、主屏／画板契约，再核实 `CreativeComposer → CreationBoard`、`LibraryComposer`、工业主题加载顺序及现有图片预览风格。技能 style 查询 `holographic minimal HUD depth` 命中 HUD / Sci-Fi FUI；仅采用细线、层次及可访问性建议，不套用道具式霓虹、扫描或持续闪烁。没有新增组件、动画库、业务状态或标签行。

## 行动

1. 定位主屏空隙来自外层 `.library-composer { bottom:16px }`，内部收起 `margin-bottom:0` 无法抵消。先用正式 App 合成数据夹具测量视口与对话框底边，旧实现出现预期失败。
2. 主屏宿主随真实 `.is-collapsed` 贴底；保留后置的多选操作条避让规则。收起仍使用原编辑器首行，未复制或重写草稿。
3. 在原工业样式入口替换生成框表面：微弱渐变、低对比边界、局部顶沿、错位后缘与分主题定向柔影；前景始终清晰。景深只作用于输入框附近的后景，渐隐层 pointer-events:none，不改变素材点击／拖动及焦点。
4. CSS 驱动展开 260ms、边缘 320ms、收起 140ms；不逐帧写 React 状态，不常驻 will-change，不持续扫描。不对正文使用 blur。减少动态效果时无动画，减少透明度及高对比时关闭后景虚化。
5. 初次画板动画断言未命中：隔离夹具 HTML 未初始化 data-theme，主屏测试曾手动设置而重载后丢失；补齐每次打开夹具的主题初始化。复查并消除重复画板选择器的过高优先级，确保浅色画板也使用浅色阴影。
6. 检查真实截图，扩大局部景深渐隐范围至面板外侧；验证模型菜单打开、Esc 与焦点恢复不受装饰影响。更新 UI 规范、复用地图及 PROJECT；仅提交本轮文件，保留并行聊天的图片预览／项目管理等改动。

## 同日反馈：顶部 HUD 标签与开放框体

用户指出顶部仍像普通按钮、整个矩形框体过于简陋。沿同一组件修改外观，不新增模式或布局行：

- 图片／视频／对话变为高于阅读面的切角标签，选中项细亮边、局部定位点与 160ms 装饰底面显现；文字及按钮命中区域不跟随标签动画移动。
- 根节点取消闭合边框、填充与矩形投影，新增一个无障碍隐藏、鼠标穿透的装饰 span，独立承载右上／左下裁角阅读面及深浅色定向柔影。根节点和控件不裁切，避免菜单及焦点被切掉；原分段边线与错位后缘保留。
- 项目、模式、规范和收起控件同行对齐，收起时装饰面回到顶部，保持贴底和首行。高对比模式回退系统色完整边界与选中标签。
- `composer-hud-ui.test.mjs`、完整 TypeScript 再次通过；回归原贴底／草稿／菜单／单行／减少动态效果，并补测 1440／900px 顶部所有控件中心线一致。人工检查深浅色正式组件截图，局部效果为 `.tmp/composer-hud/hud-tabs-dark.png`、`hud-tabs-light.png`。
- 本次纯视觉迭代复用已有验收，不为 CSS 选择器另写实现镜像单测；前一轮交互全量结果保留为历史证据，没有声称本轮重跑。仍仅源码、本地提交，未发版或推送。

## 同日反馈：透明像素标签、项目标签与关闭角

1. 用户要求标签上部透明、表面有全息像素感，项目选择同样成为标签，右上收起参考生成卡片的叉。先核对共用编辑框、`LibraryProjectPicker`／`TacticalSelect` 和工作流关闭区的实际实现；沿用既有组件，仅共享视觉规则，不引入工作流删除行为。
2. 模式和项目标签共用上沿透明渐变、切角和静态方点；点阵为 6px 间距的 1px 方点，正文底面仍不透明。标签文字区渐变收实，减少透明度和高对比时关闭纹理、使用实色表面；不增加持续动画或一行标签。
3. 项目标签高度与模式统一为 38px，整个表面都可点击。关闭区贴右沿，复用 35×34px 切角、左上定位点及居中 X；保留原 `exitCreationMode`、提示和可访问名称，仅收起并保留草稿。
4. 新增项目标签鼠标／键盘回归，先复现鼠标打开后 Esc 无法关闭：原 `onMouseDown.preventDefault()` 阻止选择器获得焦点，键盘事件仍留在编辑器。移除此局部阻止后复测通过；验证点击图标／上沿、菜单边界、Esc 焦点、方向键选择目标和 Home 返回默认项。共用选择器本身未改。
5. `node scripts/composer-hud-ui.test.mjs`、`node scripts/library-creation-parity-ui.test.mjs` 和完整 TypeScript 检查均通过。复查深浅色截图、主屏／画板、1440／900px 顶栏中心线与视频底栏单行、贴底首行草稿、减少动态效果；截图仍位于 `.tmp/composer-hud/`。减少透明度／高对比回退分支经源码复核，未将其记为本轮浏览器专项。
