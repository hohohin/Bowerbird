# 角色声音确认稿实装记录

范围：用户「认可，请实装」授权接入正式桌面源码；不发布安装包、不改 Cloud。当前产品结论见 PROJECT.md，协议见 dev-doc/VOICE-STUDIO.md。

## 复用决定

- 保留现有 commands/voice.rs 的生成、取消、冻结项目、完整 WAV 发布与幂等入库恢复。
- 界面复用 ModalShell、AudioWaveform、audioPreview、materialCatalog、importFiles、userErrorMessage、saveMediaAssetToCanvas。
- 把已有 VideoTrimTimeline 的视图及样式移到 MediaTrimTimeline，视频保留兼容导出；沿用 videoFineScrub，声音仅增加真实波形与 1–30 秒选区边界。
- 安装器需要可独立维护的 Python／模型下载状态，与已有 ComfyUI 模型与安装目录契约不同，因此新增 voice_setup.rs；未复制或修改系统 Python。
- 专属草稿与试听输入身份收敛在 voiceStudioDraft，未新增全局通用状态层。

## 操作记录（ub-mode）

1. 读取用户确认稿、ub-mode、UI/UX 技能、PROJECT 目前进展与关键约定、开发计划／复用地图、UI 规范、音频、声音及错误提示协议；确认正式后端已有可复用的任务恢复能力。
2. 记录工作区有大量其他未提交改动，为本任务涉及的已有文件保留 `.tmp/voice-ux-before/` 快照，避免把其他任务整文件混入本次交付。
3. 改造正式界面的「我的声音」、配音、录音创建、文字创建、管理和安装视图；所有子步骤复用同一个 ModalShell，避免叠加 Esc／焦点陷阱。
4. 增加正式组件回归。首次从仓库根运行时遇到 Tailwind 配置路径错误，**该次失败不计为功能 red**。改从 desktop 工作目录运行后，测试发现「台词」的辅助文字混进可访问名称；添加明确 aria-label 后通过。
5. 录音直接命名保存，波形裁剪真实传入 native；提取独立 PCM WAV 后保存声音档案。原生回归覆盖非法范围拒绝、真实片段长度、原文件保留。
6. 按项目持久化草稿；试听任务绑定来源／选区／描述身份，旧试听不会保存成不同输入的新声音。轮询增加版本判断，避免异步旧快照覆盖刚完成的操作。
7. 保存恢复只调用 recover，生成、取消、关闭重开、声音改名删除、画板确认及导出通过正式组件＋隔离 IPC 验证。浏览器创建真实 4 秒测试 WAV，验证从入点播放并在出点停止，不调用真实模型伪装试听。
8. 安装器使用专用目录及 owner 标记、固定下载来源和 SHA-256、Range／Content-Range、私有 uv 缓存；暂停保留部分文件，重开不会自动创建第二个安装任务。修正检测完成时可能覆盖正在安装状态的并发问题。
9. 先运行真实独立安装：自动下载专用 Python 3.12.13 成功，发现 CUDA 索引无 Windows TorchCodec wheel，安装测试如实失败。核对 uv／TorchCodec 官方文档及既有有效环境后，分离 torch／torchaudio 的 CUDA 安装与 PyPI 的其余依赖。失败日志保留在 setup.log，未要求用户手工输入命令。
10. 为节省重复下载，独立测试目录的模型使用既有模型硬链接；安装器仍逐文件核验固定哈希。Python、uv 和配音依赖由真实安装器下载，不能将本次测试表述为从网络重新下载全部模型。
11. 通过截图检查发现主面板滚动会带走声音列表，改为结果区独立滚动；窄窗口断言限定声音面板，宿主全局最小宽度不在本任务内修改。共享裁剪样式随组件导入，不依赖视频宿主的未提交样式。
12. TypeScript、独立 Vite 构建、正式组件回归、原生裁剪／保存恢复／下载测试和原视频裁剪回归分别执行；具体结果见下。
13. 当前工具集中无 crapper、dryer、mutator，未声称执行复杂度／重复率／变异覆盖工具。未清理仍用于声音验证的模型、参考录音与运行日志，未改动真实资料库。
14. 独立安装首次成功后，真实生成暴露 PyPI 2.0.3 不接受 `generate(seed=...)`，与前序 Git 测试版本不同。保留失败证据，改为在 runner 中统一设置 Python／NumPy／torch 随机种子，再调用稳定版公开参数；重新生成得到有效 48 kHz WAV。原生真实测试失败时也打印诊断，避免临时目录销毁后失去根因。
15. 最终以应用新装的私有 Python 执行 Rust → 内嵌 runner → 用户已批准参考 → WAV → 临时资料库的全链路，验证取消；同时复测缓存续装、CUDA 实际张量运算及全部原生声音测试。
