# 草稿编辑器实现与验证

2026-10-27：按 [PhotoSuite / PhotoSplice 研究](PHOTOSUITE-DRAFT-RESEARCH.md)实现本地最简图像编辑器。当前产品范围以 [PROJECT.md](../PROJECT.md) 为准；本轮是源码开发与隔离验证，未打包发布。

## 使用入口与功能

画板空白处右键选择「新建草稿」，直接打开 1600 × 1200（4:3）白底画布，不再先选择尺寸。进入「裁剪」直接显示画布外框、八个手柄和九宫格，可拖动边角向内裁剪或向外扩展，也可在框内拖动范围；顶部选择自由／原始／常用比例或输入精确宽高，替代右侧画布尺寸设置。Enter／应用裁剪确认，Escape 取消；保存和导出会先应用待确认裁剪。确认后作为一步撤销，已有内容不拉伸，框外像素保留；左／上扩展会移动原点并扩展覆盖画布的绘画缓冲，新增区域可绘画。白色背景为可解锁的独立图层，另有透明绘画层；隐藏背景图层即可得到透明画布。图片右键「编辑草稿」优先打开已保存工程；普通图片作为单个图层导入。原「图片标注」和 AI「分层编辑」保持各自入口。

- 画笔、橡皮：大小、硬度、不透明度、轻量平滑、压感开关和惯性强度。数位笔压力控制直径，鼠标保持设定笔径；关闭压感后数位笔也使用固定大小。惯性为距离稳定器，强度 0–100%，拖动时笔迹延后跟随，松笔补齐到末端；它与时间平滑独立，默认关闭。两工具六项参数分开记忆在本机，切换、关闭重开和应用重载均恢复各自数值；不进入工程或撤销历史。圆形笔径预览显示时隐藏系统光标，Alt 取色、空格／中键平移和控件区域恢复对应光标。
- 笔径为图像像素单位，范围 0.5–500 px，支持半像素步进；可清空后重新输入，有效数字即时用于下一笔，失焦／Enter 时规范显示，[ / ] 在细笔范围按 0.5 px 调整。
- 右侧颜色板：饱和度／明度色面、色相、HEX、常用色和最近 8 色，与顶部前景色及吸管同步；左侧提供「填充选区」，使用当前前景色填充。支持键盘调色，最近色保存在本机。
- 图层：新建、导入、粘贴、拖入、复制、删除、上下排序、显隐、锁定、不透明度、移动及等比缩放；位置和尺寸可通过数值输入。
- 文字：直接在画布输入中英文及多行文字，支持字体、字号、颜色、粗体和对齐。
- 矩形选区与自由套索：共用顶部「新选区／增选／减选」模式，可合并重叠或分离范围，也可减去范围形成空洞。按住拖动圈出范围，松手闭合；凹形与自交路径按 even-odd 规则处理。画笔、橡皮、形状、填充和清除遵循实际轮廓，包围盒仅用于局部重绘／历史范围；Escape 取消未完成的增减选手势并保留原选区。Delete／Backspace 清除选区内像素，取消选区仍用按钮或 Cmd／Ctrl+D；移除原「清除选区」按钮。减空后的选区仍限制编辑，不能误变成整层清除或删除图层，可继续增选或取消选区。裁剪、矩形／椭圆／箭头、吸管保持。
- 滚轮缩放、空格／中键拖动、适应窗口、撤销／重做、PSD 导出、保存后重开工程。

Tab 或顶部「素材库」可展开编辑器内的素材库，复用全局／项目、搜索、标签、集合和筛选。图片拖入画布成为独立图层，也可双击或多选后「添加到草稿」。成功导入后自动切换到移动工具、取消旧像素选区，选中新图层并显示高亮边框；多张导入选中最后一张，可直接拖动。导入失败保留原工具及选中状态。拖动时收起库并保留拖拽源直到结束，不向底层项目画板添加对象；导入按一次操作撤销，错误保留已有文档。输入框中的 Tab 和 Shift+Tab 保留焦点导航，关闭确认框仍约束焦点；Esc 优先收起库。

草稿首次保存到画板时创建一张图片卡片；以后保存更新原卡片，保留节点 ID、位置、尺寸、层序、锁定、分组和连线，重开／重载后也不新增卡片。底层 PNG 与工程仍保存不可变版本，已被生成任务引用的旧文件保留。普通图片首次转为草稿时另建草稿卡片；旧版已产生的多个草稿卡片只更新当前选中的实例，不批量隐藏其它对象。空白画布未编辑直接关闭不会入库；有修改时关闭会提示保存、放弃或继续编辑。保存失败保留现场，可重试。

## 快捷键

| 操作 | 按键 |
|---|---|
| 移动／画笔／橡皮／文字 | V / B / E / T |
| 吸管／矩形选区／自由选区／裁剪／矩形 | I / M / L / C / U |
| 临时取色／平移 | Alt 单击／空格拖动或中键拖动 |
| 缩小／放大笔径 | [ / ] |
| 保存 | Cmd / Ctrl + S |
| 撤销／重做 | Cmd / Ctrl + Z / Shift + Z；Ctrl + Y |
| 全选／取消选区 | Cmd / Ctrl + A / D |
| 清除选区或删除未锁定图层 | Delete / Backspace |
| 素材库展开／收起 | Tab（输入框外）；顶部按钮 |
| 应用／取消裁剪 | Enter / Escape；双击框内应用 |
| 微调裁剪手柄 | 聚焦手柄后方向键，Shift 加速 |
| 取消当前手势、退出文字或取消选区 | Escape，按当前交互状态处理 |

文字和数值输入保留自身按键行为，IME 组合期间不触发工具快捷键。画板外层快捷键在编辑器开启时停用。离散编辑命令先取消未提交手势，防止半笔像素进入其它操作的撤销记录。

## 实现契约

`DraftEditor.tsx` 管理工具、手势和编辑状态；`draftDocument.ts` 提供图层模型、统一预览／PNG 合成和 PSD 适配；`draftBrush.ts`、`draftCrop.ts` 与 `draftHistory.ts` 独立于 React。裁剪预览按当前范围重绘原图层，显示保留的框外像素及真实透明度；预览缓冲最长 2048 像素，确认时才分配扩展图层。`useDraftBrushPreferences.ts` 保存独立工具偏好；`useDraftLibrary.tsx` 复用现有库并限定导入目标，只用素材 ID 解析可信记录，不读取拖拽文本中的任意路径。复用已有文字绘制、视口导航和 PSD 导出能力，没有复制 PhotoSplice 源码或笔刷资源。

画笔按距离生成圆形笔印，采用时间平滑、每笔覆盖率与落笔前像素合成。每帧收集 coalesced samples，绘制不逐样本写 React 状态；使用 128 × 128 局部瓦片保存前后像素，自由选区按瓦片缓存像素中心命中 mask，通过变化区域刷新预览。一笔只提交一条历史；Escape、失焦、pointercancel 或捕获丢失还原未提交笔画。窗口缩放和平移不产生历史。

自由选区采样最多 2048 点，长手势抽稀并保留首尾；图层坐标转换同时映射轮廓与包围盒，选区不进入工程快照。单个选区的普通 Canvas 操作使用路径抗锯齿裁剪，画笔使用像素中心 mask，边界 alpha 可有差异。增减选按画布像素合并为扫描行区间，轮廓只显示合并后的边缘，支持空洞与独立区域；图层变换同步映射区间坐标，填充、清除、形状和画笔遵守同一组合范围。抬笔事件的零压力不会把惯性补尾错误压成零宽；整笔补尾仍属于同一步历史。

工程 JSON 使用 `schemaVersion: 1`，包含独立 `documentId`、画布尺寸、按底到顶排列的图层，可选 `backgroundLayerId` 标识背景层。栅格图层保留独立 PNG，文字图层保留可编辑属性；图层保存位置、显示尺寸、透明度、显隐和锁定状态。旧快照的默认锁定背景可兼容识别。历史仅在当前会话中保存，重开恢复当前工程状态。

原生命令为 `draft_workspace_load`、`draft_workspace_save`、`draft_workspace_asset_ids` 和 `draft_workspace_canvas_upsert`。保存依次写入独立 PNG、缩略图及 `layers/<ULID>.json`，文件同步完成后，在一个 SQLite 事务中建立资产、工程指针、保存收据和项目关联。`saveId` 相同且内容一致时返回同一资产；同 ID 不同内容拒绝。编辑后使用新的保存 ID。普通图片入库的内容去重不参与工程身份判断。

画板保存冻结项目、来源节点及首次落点。专用 upsert 核验保存资产的真实工程身份，在事务中按来源节点或同项目的 `draft_document_id` 找到原卡片，仅更新 asset／snapshot；旧节点可从 `draft_save` 收据识别工程。通用布局更新仍不能改素材身份。来源节点已删除、隐藏或跨项目时拒绝复活。节点更新失败或响应丢失后重试复用已保存资产和节点；编辑期间切换项目不会把草稿插入新项目。事务或文件写入失败清理本次文件。工程随整个资料库迁移；随图 sidecar 只带小指针，不是可独立恢复的工程包。项目仅移除成员时保留工程，删除资产时只清理合法且无其它引用的草稿文件。

2026-10-27 修复显示生命周期：真实应用启用 React StrictMode，effect 清理取消了 RAF 却未复位帧编号，导致其后所有重绘被永久跳过，像素已写入但预览一直透明。现在取消后同步清空帧编号和变化区域；完整交互夹具默认 StrictMode，并增加普通／StrictMode 对照验证首次白底、按住笔画、松手、保存及重开。此前仅普通模式的浏览器验证未覆盖该问题。

## 限制

- 画布及单图层每边最多 4096 像素，最多 32 层；实际图层缓冲区总计最多 6400 万像素。非破坏裁剪保留框外像素，因此原图层与扩展范围并集也须在单层 4096 限制内；超限在分配前报错，原文档保持。
- 单 PNG 最大 30 MiB，序列化工程最大 256 MiB。
- 组合选区限制在画布内，最多 65,536 个水平区间；超复杂轮廓提示重新选择并保留原选区，不截断为错误范围。
- 撤销默认最多 100 步、128 MiB；超过预算淘汰最早记录。单次操作超过预算时保留当前结果并重建历史基线，避免跨越未记录操作撤销。
- 这些是文档与历史预算，不是整个进程的峰值内存保证；解码、序列化、导出还会有临时缓冲区。
- 首版不包含魔棒、滤镜、蒙版、混合模式、倾斜笔刷或 PSD 导入。PSD 导出保留图层和文字，透明通道／层序／文字属性有反读验证。
