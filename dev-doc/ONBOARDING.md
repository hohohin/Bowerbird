# 项目画板入门引导

实现记录：2026-09-11。项目定位与当前决策以 `PROJECT.md` 约定 16、44 为准。基础引导及退出/遮挡修复已纳入 2026-09-14 构建的 Windows 26.9.14 本地安装包；原生窗口验收仍待进行。产物与本轮复跑记录见 `PROJECT.md`。

## 入口与主线

- 空库且无项目的新用户首次看到欢迎页；有素材、项目或旧版 `bowerbird.tutorialSeen` 的用户看到一次「新版变化」。等待实际数据库计数，不用尚未加载的素材列表判断空库。
- 设置 → 系统设置 → 入门引导可随时重新打开。欢迎页提供示例、自己的图片、继续上次进度和跳过入口。
- 示例创建独立的「我的第一次创作」空白项目。两张随包图片分别是护发产品和蓝色配色参考，附带已有维度；用户自己拖入画板。
- 主线是普通图片生成：拖图 → 移动卡片 → 写目标并加入参考 → 借用维度 → 主动发送并等待实际结果，取得结果后点击「完成入门引导」。已按用户要求删除「从结果继续修改」，主线共五步。视频和 Agent 执行不作为本轮主线的完成信号。
- 右上角是可收起的任务清单，只描边相关控件；保留正常页面交互、维度环关闭手势。打开登录、设置等模态窗口时立即隐藏清单和暂停后的恢复气泡，关闭窗口后恢复；引导浮层层级低于模态遮罩。
- 欢迎页、展开/收起的任务清单和恢复气泡均提供「跳过入门引导」。欢迎页关闭也视为跳过；跳过立即移除浮层并持久保存 skipped，不清空项目、草稿或步骤，不依赖画板保存成功。恢复气泡右侧的关闭按钮执行跳过；以后可从设置重新打开并继续原进度。已完成状态不会被跳过改写。
- 第四步可明确跳过维度，清单显示「已跳过」。第五步可「先完成准备，稍后生成」，记录 prepared 与 paused，不宣称已经生成或整课完成。

## 数据与恢复

`lib/onboarding.ts` 定义 v2 进度与纯推进判断；`lib/onboardingStore.ts` 独立保存 `bowerbird.onboarding.v2`。记录项目、示例项目、开始时间、生成任务、步骤、完成类型、升级页已读和专题提示关闭状态。重启后 active 恢复为 paused，错误或未知版本数据回到初始状态。

`OnboardingTour.tsx` 只在学习期间检查当前已加载的项目画板和真实编辑器内容；其他项目、没有结果的失败任务、旧任务不会推进生成步骤。移动卡片以位置变化判断，加入参考与维度以编辑器实际内容判断。旧版停在第六步的用户恢复到第五步，保留项目与任务标识；已经完成的状态不清空。

暂停前调用画板现有 flush；失败时保留当前学习状态并显示保存错误。恢复先检查项目仍存在，路由切换沿用既有保存协议。示例准备过程中用户已切换页面时，保留新项目并提示重新进入，避免迟到请求抢走当前页面。

后端 `commands/preset.rs::create_onboarding_project`：

- 直接读取随包 `PRESET_SPECS` 的前两张图；不经过会自动分析的文件夹导入流程，不启动模型或要求账号。
- 复制为新的 imported 资产，名称带「示例」，维度分析标记 `bundled-example`。不覆盖去重命中的用户资产，不伪装生成结果，并清除指向安装资源的 `origin_path`。
- 使用 `onboarding:v2:{projectId}` 来源标记保护示例身份。重复打开同一个示例项目不重复导入、不重置用户编辑；用户删掉的素材也不自动补回。
- 资源缺失时明确报错；与已有普通项目的标识冲突时拒绝修改。部分导入失败时移除失败项目关系，保留已入库资产，重试可能留下额外示例副本。
- 注册新 Tauri 命令，因此仅刷新旧桌面进程前端不足以使用新示例入口，需要重新构建/启动对应后端。

## 按需提示

欢迎页和完成页提供显著的「学习集合与视觉规范」入口。集合教程单独解释四件事：按品牌/主题命名、添加或导入图片、主动提炼、保存后显式选择规范；可以直接创建集合或打开已有集合。集合面板内也有同一份可收起/重开的教程，空集合首次默认展开。已有素材加入集合会改变素材库归属，不改变已有关联画板布局。提炼仍可跳过，不自动调用模型。

集合创建复用 UI「集合」的普通 folder API，不能误用对应收藏夹的 kind=collection。创建成功、随后刷新失败时保留新 ID，重试打开而非再建一份；侧栏折叠时也可打开集合面板。进入集合教程前保存当前草稿并暂停进行中的画板主线。欢迎页另外保留探索、反推维度、视觉规范、本地分类、画板整理五个折叠主题，其他页面的短提示在主线激活时隐藏。

探索提示放在右侧工作区的正常布局中，避免遮挡素材栏开关；原生网页区仍由既有浏览器组件管理。说明明确网页拖图当前适用于 Windows。视觉规范沿集合提炼、保存后主动选择；本地分类说明首次约 756 MB 下载与本机推理，不将分类标签和反推维度混用。
