# 音频预览隔离验证

2026-11-01，Windows 本机。范围为独立 Rust 解码器、网页交互样稿与隔离 WebView2；尚未接入正式素材库。素材均为本次合成，不读取用户库。Mac 原生验收未执行。

当前交互已按用户反馈改为：悬浮仅显示时间针；点击波形从点击位置临时试听，移出停止；左下独立播放按钮从头持续播放，移出或浏览其他卡片不中断，直到主动暂停、自然结束或启动新的播放。下文首次悬浮版和首次点击版数据保留为历史基线，不再描述当前完整交互。

## 波形生成与热缓存

Release 构建，Symphonia 0.5.5。每个样本一次波形缓存未命中、五次命中，系统文件缓存未清空。表中时间为进程内提取/缓存服务时间，不包含进程启动、IPC、页面绘制或出声。

| 样本 | 时长 | 首次生成 | 热命中均值 | 解码进程峰值工作集 |
|---|---:|---:|---:|---:|
| WAV 提示音 | 12 秒 | 6.86 ms | 0.338 ms | 4.85 MiB |
| FLAC 雨声 | 24 秒 | 14.28 ms | 0.330 ms | 2.56 MiB |
| VBR MP3 节奏 | 18 秒 | 10.88 ms | 0.389 ms | 2.56 MiB |
| AAC/M4A 氛围 | 36 秒 | 21.20 ms | 0.402 ms | 4.96 MiB |
| WAV 脚步 | 8 秒 | 4.20 ms | 0.357 ms | 2.56 MiB |
| VBR MP3 长音频 | 1 小时 | 2,038.34 ms | 0.325 ms | 5.16 MiB |
| FLAC 长音频 | 1 小时 | 1,634.39 ms | 0.356 ms | 4.52 MiB |
| PCM WAV 长音频 | 10 分钟 | 221.38 ms | 0.378 ms | 4.40 MiB |

所有热命中均为 `sourceBytesRead=0`、`decodedFrames=0`。原件前后 SHA256 对照，8 个样本全部不变。内存数据是 10 ms 轮询读取进程的 PeakWorkingSet64；短进程可能在结束前未被完整采样，不是完整应用内存承诺。波形数组上限为 2,048 组 Float32 min/max，容量 16 KiB；实际 JSON 为约 35–78 KB，不能把理论 16 位二进制的 8 KiB 当作本实现的文件大小。

首轮未缓冲的 JSON 文件逐段读写使热命中为约 25–41 ms。加入 BufReader/BufWriter 并显式 flush 后复测得到上述结果；未通过跳过版本校验换取速度。

原始结果：[waveform-windows.json](evidence/waveform-windows.json)。执行：`benchmark.ps1`。初轮对照保留在仓库 `.tmp/audio-preview-fixtures/benchmark-20261101-092401/results.json`。

## 行为与产品边界

- Rust 11 项测试通过，包含声道静音/反相、短文件、长文件有界缓冲、缓存命中、版本变化、同版本不同原件、取消/解码中变化、损坏/截断 WAV 和输出不能覆盖原件。Clippy `--all-targets -- -D warnings`、rustfmt 通过。
- 波形按文件峰值归一化显示，静音保持中线；不会改变播放音量，不作为文件间响度比较工具。鼠标时间针与播放进度针分离，悬浮不加载或播放音频；点击波形按本次点击坐标临时试听，左下播放按钮从零持续播放。仅临时试听在离开整个波形预览区域时停止。
- 预览有 1,200 条卡片压力模式，复用六个真实音源；验证的是挂载/绘制/缓存和播放管理，不代表 1,200 个不同音频文件已完成后台索引。
- 当前 spike 有单次解码取消能力，不是已经接入正式后台队列；磁盘缓存总量淘汰、真实目录音频扫描/筛选/统计、正式资产详情和 Mac 兼容仍属于下一阶段。
- 波形解码支持和 WebView 播放支持分别验收；不能按文件扩展名承诺所有编码变体。Opus 不在本次内置解码支持范围。

## Windows 原生播放（首次悬浮版基线）

隔离 Tauri 2.11.5 / Wry 0.55.1 / WebView2 Edge 156，独立 profile，没有生产初始化、数据库或登录。未开启 Network 域、未连接 Playwright 的裸 CDP 对照中，8 个文件的首次 pointerenter 均记录 `hasBeenActive=false/isActive=false`，未静音且音量 0.03，`play()` 成功后真实时钟继续推进超过 0.2 秒。长 MP3/FLAC 与十分钟 WAV 的 pointerenter→play fulfilled 分别约 51.6/33.2/31.9 ms；这是播放器接受播放的延迟，不是声卡首次出声或听感测量，也不包含正式 UI 的 90 ms 停留。

实际波形 UI 另行通过：短 WAV 与一小时 MP3 均从中点的原生 asset URL 播放；移到标题区后暂停且 src 清除。100 次快速跨卡片移动在 90 ms 停留策略下触发原音频请求 0 次。观察到推进超过 0.2 秒的耗时为约 483/431 ms，其中包含停留、加载、播放推进和测试轮询，不能标作纯开始播放延迟。

带网络观测的原生测试记录 Range 请求与 206 响应。Content-Length 总和只代表观察到的协议响应长度，取消请求可能不完整；不是物理磁盘读量，也不能与没有 Network 域的内存对照混为同一轮。

初轮使用 Playwright 和 Network 域时，3×100 次快速切源后私有内存约 384→482→582 MiB。调查发现 Playwright 自己也启用 Network 域，所以只关闭额外 session 不足以排除响应缓存。换成完全无 Playwright/Network 的裸 CDP，同样三轮切换并各自然等待 5 秒后，整个隔离进程组私有内存为 **240.33→251.18→249.05 MiB**，没有复现逐轮约 100 MiB 增长；没有强制 GC。结果支持观测工具干扰的解释，尚不能证明具体保留机制或任意时长无泄漏。此内存包括 WebView2 全进程组，不等于 4–5 MiB 的独立波形解码进程。

[原生摘要与测量边界](evidence/windows-native-summary.json)。完整证据保留在 `.tmp/audio-preview-native/run-1793496852579`（裸 CDP）和 `run-1793496942523`（真实 UI）。早期失败轮也保留：有一次测试把设定 currentTime 错当推进，已改为等待 play fulfilled 后继续推进；有一次代理丢失 CSS Accept 头，波形铺满页面导致鼠标未真正移出，修正代理后保留原停止断言通过。

## 按钮持续播放验收

按钮与波形点击共用一个播放器，但生命周期分开：按钮从零持续播放，波形点击为移出停止的临时试听。悬浮其他卡片不换源；点另一个按钮或波形才替换当前播放。同一卡片再次点波形会切为临时试听。播放中的左下按钮仍是暂停，暂停后再播从零开始。

真实浏览器回归覆盖按钮移出/焦点移出后时钟继续、其他卡片悬浮不切源、两种入口替换且不重叠、延迟音源在移出后才完成加载仍持续播放、同卡波形切回临时模式。滚动离屏不再停止按钮播放，回来恢复同一播放器的暂停状态与进度；仅保留一个离屏活动卡片，离屏停止进度针 rAF。已有临时试听停止、源复用、迟到请求、可见列表和缓存边界仍通过。[浏览器结果](evidence/browser-continuous-ui.json)。

持续模式另验证 blur 与 visibilitychange 事件：模拟 hidden 后真实媒体时钟继续，恢复可见没有新增 loadstart；这是事件处理与真实媒体验证，不是操作系统长期后台调度测量。

Windows 原生 UI_ONLY 使用 12 秒 WAV 与一小时 MP3，均从约 0.11 秒开始，移出后继续至约 0.33 秒，悬浮其他卡片后继续至约 0.60 秒且没有换源或新 loadstart。点波形切回临时试听后仍从实际点击位置推进，同源 loadstart/src 变更为 0；移出暂停并释放源。按钮重播、主动暂停和跨卡新播放替换通过；始终一个 audio，13 个请求全部 Range/206。[原生摘要](evidence/windows-native-continuous-summary.json)，完整记录 `.tmp/audio-preview-native/run-1793498472913/result.json`。这轮没有重编译 Rust 或重跑全格式/内存压力，不扩展先前的 Mac 和听感验收边界。
