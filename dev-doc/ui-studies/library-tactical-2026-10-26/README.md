## 恢复实装前样式

先保存之后的工作区改动，在仓库根目录检查补丁是否仍能安全撤回：

```powershell
git apply --reverse --check dev-doc/ui-studies/library-tactical-2026-10-26/integration-with-focus-fix.patch
```

检查通过后执行：

```powershell
git apply --reverse dev-doc/ui-studies/library-tactical-2026-10-26/integration-with-focus-fix.patch
```

需要重新接回本版时，去掉 `--reverse`，同样先 `--check` 再应用。恢复的是源码，需要重新启动开发版本或构建安装包后才影响运行中的应用。

如果检查失败，说明相关文件已继续演进。此时依据 `before/` 和补丁逐处合并样式差异，不要整批覆盖当前文件；这样可保留后续功能。补丁不回退本文档、项目记录、素材、数据库或账号数据。
