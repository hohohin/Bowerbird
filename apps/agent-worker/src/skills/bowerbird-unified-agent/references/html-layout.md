# HTML 图文排版

根据用户提供的内容组织阅读顺序、字体层级、留白和图片位置。精确文字由 HTML 文本节点承载，图片作为视觉资源；保留用户文案，不虚构产品事实。

`compose_html` 编写一份静态 HTML/CSS 文档，`render_html` 将其输出为截图。生成的图片通过步骤依赖交给排版。渲染规格在执行时提供。

采用受支持的语义标签、系统字体、flex/grid 和自然文档流，图片保持比例。文档只使用当前工具提供的资源别名，不访问网页或执行脚本。具体资源映射和 sanitizer 契约由执行工具提供。

按内容需要安排区块；标题、正文、图片和注释的层级应服务于用户要求的阅读体验。
