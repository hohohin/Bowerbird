# 图片标注复用截图工具

用户要求：让图片标注尽可能复用截图代码和工具，保留此前单行工具栏、悬停滚轮调粗细、画面内文字编辑与镜像行为。本轮按 ub-mode 执行；项目结论在 PROJECT.md，本页保存行动与验证。

## 行动记录

1. 阅读当前约定、架构入口、复用地图和 UI 规范；检索两个编辑器与调用方。确认形状、渲染、文字编辑、历史、滚轮已共用，重复集中在工具按钮、拖绘手势和图片 SVG 预览。采用现有截图实现，不引入新标注依赖。
2. 新增 `annotation-shared-tools-ui.test.mjs`，先确认图片入口缺少「直线／折线」时失败。隔离脚本首次受到 Windows 沙箱 realpath／localhost 限制，在正常执行权限下复现预期失败。
3. 提取 `AnnotationTools`、`useAnnotationDrawing`、`useAnnotationCanvas`，同时接入截图和图片标注。工具组保留宿主按钮样式；手势管理拖绘／Shift／折线；Canvas 保留静态合成和临时层，移动指针不重放全部已提交标注。
4. 图片入口使用完整工具类型，接入截图既有区域效果、橡皮擦与实心形状，并使用公共历史提供重做。保留裁剪交互 SVG，移除重复绘制 SVG，仅为文字保留命中区域。扩展坐标元数据与描述，输出仍保留来源身份。
5. 增加透明素材实际截图检查，先复现底图被重复合成（半透明像素实际 196/205/213，预期约 137/154/171），随后修复；检查橡皮擦临时预览与导出恢复原图 alpha。区域效果在裁剪后完全位于图外时跳过，防止建立无效采样画布。
6. 增加未完成折线直接输出和键盘镜像后撤销检查，先复现 Enter 被折线完成处理拦截及撤销丢失折线，再统一图片变换的待编辑结算与快照顺序。
7. 原回归中的 SVG 结构断言改为导出元数据／实际 Canvas 像素与文字命中操作，保留原功能覆盖。`annotation-loading-ui` 的旧「素材加载失败：」前缀断言与当前错误展示不符，只更新测试期待，不修改产品错误处理。
8. 核验图标按钮名称、选中状态和 tooltip；复查 800–1440px 单行布局，新增工具没有恢复粗细滑杆。更新桌面复用地图与 PROJECT 约定。工作区包含其他未提交任务，提交仅纳入本轮文件及 PROJECT 本条增量。
