# 标注图片平移

用户要求：标注功能中的图片能够移动。按整张图片及标注在编辑窗口内平移实现，沿用 ub-mode 与已有复用约定；当前行为以 PROJECT.md 为准。

## 行动

1. 阅读当前项目约定、UI 规范、标注复用地图，并跨模块检查截图、图片查看器和图层编辑器。截图保留固定捕获坐标；`useImageZoom` 已管理图片位移和窗口级拖动，因此复用这一公共入口，标注绘制继续使用截图共用核心。
2. 新增真实 ImageAnnotator 的隔离浏览器测试，先观察到缺少「移动图片」工具的断言失败。
3. 为共用图片 hook 增加 Pointer Events 拖动入口、指针捕获与取消、方向键位移方法和是否偏移状态；沿用原位移计算与复位逻辑。鼠标旧入口与新指针入口按事件身份隔离，避免兼容鼠标事件重复操作；pointerup 结算最终坐标，取消／失焦结束拖动。
4. 标注顶部增加手形按钮，支持手形拖动、空格＋左键及中键临时平移；将同一位移作用于底图、Canvas 标注、文字编辑器、SVG 命中区域和裁剪 UI 的父层。右下角居中入口始终留在窗口内；手形模式支持方向键与 Shift 快步移动。
5. 标注工具选择后将焦点交回编辑舞台，避免空格误激活刚点击的工具按钮；主动键盘聚焦的按钮仍保留空格操作，输入框／中文组词不进入临时手形。平移先于裁剪／标注命中判定，临时移动保留正在编辑的文字；绘制中不切换平移。
6. 平移保持视图状态，不改图像操作序列、坐标元数据或编辑历史；落点和滚轮继续按移动后的 SVG 实际边界计算。重新打开在布局阶段复位。测试等待新图加载完成，避免把重开过程中的旧节点或加载占位当作稳定结果。
7. 检查公共 hook 的所有调用方，运行已有查看器回归。更新标注复用地图与项目约定；仅暂存本轮代码、测试、文档及 PROJECT 新增段落，保留工作区其他任务。临时构建保留用于复核，提交辅助脚本完成后清理。
