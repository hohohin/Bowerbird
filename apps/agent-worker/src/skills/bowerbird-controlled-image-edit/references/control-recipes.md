# 控制参考配方

只采用当前意图需要的配方。控制参考用于隔离一个高约束属性，不能制造来源图中不可见的新事实。

| 约束 | 推荐表达 | 排除内容 |
|---|---|---|
| 全身动作 | 关节关键点、躯干轴线、脚底位置 | 人脸、服装、背景、画风 |
| 头肩动作 | 头部椭圆、面部中线、视线、颈轴、肩线与裁切 | 真实五官、头发、首饰、文字 |
| 人物身份 | 用户提供的清晰身份参考 | 生成的未知侧脸、动作和服装 |
| 产品一致性 | 原产品图、轮廓比例、关键结构锚点 | 未知背面、接口和猜测结构 |
| 服装 | 版型、覆盖范围、领袖结构、材质与颜色 | 人脸、首饰、品牌文字、背景 |
| 饰品和小物 | 原始干净产品图、佩戴位置和尺度 | 产品图背景、标注框、箭头、文字 |
| 构图和站位 | 边界框、中心点、地平线、层级和裁切 | 身份、材质和画风 |
| 手持与接触 | 手部关键点、接触点、遮挡边界 | 新造手指、产品细节和背景 |
| 文字与包装 | 版式网格、文字框、用户逐字文案 | 模型改写文案或新品牌元素 |

## 非显而易见的约束

- 头肩姿态不能只用信息不足的火柴人；至少表达转向、俯仰、侧倾、视线、颈轴、肩线和裁切。
- 只有一张产品图时，不生成未知视角并把它当成真实控制事实；必须换视角时在计划假设中披露近似推断。
- 产品进入新场景时，优先分离环境生成和产品插入，避免每步同时重绘两者。
- 服装参考混有人脸或首饰时才生成无身份服装控制参考；干净平铺图直接使用。
- 饰品阶段强调真实比例、连接点、重力、遮挡、透视与光线，并只改局部。

阶段提示应稳定表达：唯一底图、当前参考只控制的属性、只修改内容、严格保持内容、禁止带入内容，以及控制线/箭头/示意风格不得出现在最终图中。
