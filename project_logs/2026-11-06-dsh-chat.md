# 对话接入本机 DSH

2026-11-06。产品约定以 PROJECT.md 为准。

## 范围与行动

1. 按用户确认的两条路径开发：连接用户已有 DSH，沿用其认证；应用管理的本机 DSH 经 Cloud 调模型，测试价格 0 Bcoin。模型密钥不得下发桌面。
2. 读取当前架构、对话、Harness、定价、错误展示与复用地图。现有 ds-inbox 只有投递，不满足面板回复／停止；复用其本机认证与协议知识，对话数据、卡片事务和 Cloud completion 沿现有实现。
3. 按 ub-mode 的“Send the bulk elsewhere”分离只读本机协议调查、托管模型协议调查及前端实施；主线程负责原生会话、运行时、整合与验证。先写可观察行为测试，不调用真实模型。
4. 保存共享文件既有差异，保留其他未提交任务。crapper、dryer、mutator 工具未提供，不宣称运行；以行为测试和差异审查注明验证范围。
5. 先观察到原生未知 provider、连接边界与工具授权测试的预期失败，再实现 0053 保留旧 provider 的迁移、固定会话来源、非 Codex 参数拒绝和两种 DSH 原请求恢复。前端先复现 DSH 草稿与门控失败，再复用现有模型菜单和弹窗。
6. 本机 DSH 用专用 session／preset 和短期 loopback 建卡通道；通过实际安装的 DSH 与确定性模拟模型验证，发现 preset 层空工具白名单会连自身工具一起过滤，改在目标 agent 上限定建卡；同时纠正工具执行上下文的 session 身份字段。验证冷读历史不依赖已删除 preset、不重新启动 Agent。
7. 托管 DSH 使用原生 ACP 循环，单次模型／工具经标准输入输出交回宿主。先以模拟 completion 跑实际 DSH，再从空目录安装验证 manifest／lock。发现上游 caret 依赖会解析到不兼容 Cordis，钉住兼容版本；更新本轮 YAML 依赖至修补版本，全新安装 audit 为 0。生产不依赖 spike 目录。
8. 宿主复用 Cloud 原账号／幂等键／零价账本；校验当前模型的工具 ID 与精确参数，取消后关闭工具、终止私有进程树，不重发未知请求。共享源代码中的 Codex 和原 Cloud 分派保持回归覆盖。
9. 合成 IPC 页面验证 DSH 准备、登录链接不回传、URL 回填、独立于 Codex 的发送门控、0 Bcoin、角色和只查询原请求的恢复。修复菜单 footer 打开设置时没有收起旧菜单的遮挡；公共 footer 增加 close 回调并保留原节点用法。CUA 验证多行输入与本机 DSH 回复终态。
10. 更新项目约定、源码 schema 状态、近期里程碑和复用入口；只提交本轮文件／增量，保留其他素材库与画板改动。结束时清理本轮失败测试副本和验收服务，保留日志、截图与最终构建证据。
11. 并行创作框提交后重跑 DSH 界面专项仍通过；新测试允许自动选择空闲端口，避免与其他验收相撞。暂存复核发现开工前逆补丁会撤回期间已提交的其他文档调整，改为按最新 HEAD 只重建两份 DSH 文档增量；不改工作区原有内容。已清理 4 份本轮测试 exe 副本，验收端口不再监听。
