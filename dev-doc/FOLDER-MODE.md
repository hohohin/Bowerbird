# 主瀑布流文件夹模式

产品决定见 PROJECT.md。开发基线为 prod@2dd1e14；后续源码在 dev，未发布。

## 交互契约

- 工具栏电脑按钮切换主区数据源，不新增侧面板。保留原素材库组件及其搜索、筛选、选择、项目展开和滚动状态；目录模式拥有独立搜索、选择、历史和标签。
- 文件夹优先，媒体采用现有瀑布流布局和缩略图大小控件；单击选择，双击/Enter 进入目录或预览图片、视频。当前层列举，不混入子目录媒体。
- 导航提供路径输入、选择目录、返回、上一级、刷新和返回素材库。打开失败保留可返回的位置，迟到请求不能覆盖新目录。
- 图片支持 PNG/JPEG/WebP/GIF/BMP；视频支持既有 MP4/MOV/M4V/WebM/MKV/AVI，播放取决于 WebView 编码支持。封面失败显示视频占位，不阻止浏览。
- 浏览/预览/分类不登记到主库，不复制原媒体。显式加入画板才登记外部资产；显式复制到素材库才复制原文件。目录模式不提供磁盘删除/改名。

## 分类契约

- 自动分类可选择素材库或文件夹。选定根目录，可选包含子目录；只分类图片，原地写 `.bowerbird/classification.json`。
- 文件身份使用根目录相对路径和内容指纹；记录仅包含版本、扫描范围、标签/说明、归属来源、人工正反例和模型观察，不含凭据、主库 ID 或机器绝对路径。
- 复用现有本地/Jev+Cloud 引擎，在独立内存数据上下文运行，所有候选词、正反例和结果均限定为当前目录。设置及模型安装沿应用现有配置，Cloud 沿既有上传/计费说明。
- 分类逐图提交，保存用临时文件刷盘再替换。单个分类目录只允许一个写入者；未获锁、只读、失联或保存失败明确报错，不声称完成。NAS 真机锁与断线行为须另验。
- 子目录继承最近祖先的分类根（仅当该根开启递归）；显式建立的独立子目录分类根优先。扫描跳过嵌套分类根和符号链接，避免范围重叠及目录循环。
- 新增/内容变更进入待处理；变更清除旧自动判断，保留人工归属，人工示例内容变化需重新确认；重命名暂按新路径处理，不凭同名猜测身份。
- 首版显式扫描，不增加目录后台监听或多机协同编辑协议。

## 验收

1. 主库/目录往返恢复搜索、筛选、选择和滚动；目录双击、键盘、返回、路径错误及迟到响应。
2. 图片和视频静态封面/按需预览；切换目录释放媒体；深浅主题、900px 窄窗口、缩略图缩放。
3. 分类 A/B/主库完全隔离，复制整个根目录可重开；新增、变更、停止/重试、人工保护、只读/写锁/损坏数据。
4. 隔离临时目录和模拟模型验证，不扫描用户盘、不调用付费 API。真实 NAS、原生视频编码与 Mac 验收单独注明。

## 本轮验证与限制（2026-10-16）

- TypeScript、Vite 隔离 production 构建通过。
- Rust 文件夹专项 4 项：范围/主库隔离、根目录搬迁、非递归/嵌套根、原图变更、写锁冲突及损坏记录保护；分类模块既有回归通过，真实模型项保持忽略。
- 外部引用 9 项通过；另显式运行 1 项本机 FFmpeg 合成短视频，验证视频元数据、封面、无副本引用、重新定位、显式复制及原视频保留。
- `scripts/folder-mode-ui.test.mjs` 使用真实组件和模拟 IPC，覆盖导航/键盘/双击预览、搜索/标签隔离、选择示例、递归分类参数、错误与迟到响应、无隐式导入、主库滚动/选择/筛选恢复、900px 深浅主题。既有分类面板与工具栏 900–1920px 回归通过。

- 初始扫描逐个读取图片并校验指纹；当前不可读取/损坏图片会报错停止准备，保留上一份分类记录。未提供自动重命名识别、目录监听、写锁异常退出后的自动抢占。NAS 多设备并发/断网、原生 WebView 视频编码、Mac 界面仍待实机验收。
- 测试不扫描用户目录、不调用真实模型或付费 API；未打包、部署或推送远端。
