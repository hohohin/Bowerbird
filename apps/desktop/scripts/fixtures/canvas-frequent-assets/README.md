# 画板素材库常用素材隔离验收

在 `apps/desktop` 执行 `node scripts/canvas-frequent-assets-ui.test.mjs`。

夹具复用 `canvas-reference` 的真实 `CanvasWorkspace` 与模拟 IPC，提供常用素材读取／检索／固定／移除／阈值保存 5 个 IPC、合成 SVG 素材、两个项目的独立成员及浏览器 sessionStorage 偏好。不会连接 Tauri、读写真实素材库、提交模型请求或访问外网。脚本自建 Vite 1789 服务并在结束时关闭；需要已安装 Chrome 和仓库 Playwright。

覆盖：默认严格大于 10 次（10 排除、11 包含）、次数降序、阈值上下箭头／输入、Enter／失焦保存、Escape 恢复、负数／小数不提交、保存失败回退、阈值跨重载／范围切换保持。阈值改为 3 后继续覆盖 3/4 次边界；改阈值不恢复排除项、不影响手动固定。隐藏素材不自动检索、无可见名称且保留无障碍名称／悬停提示、底部两行、空手动行压缩为单行、整体收起仅保留标题栏。移除后普通刷新／关闭重开／页面重载保持隐藏，显式检索恢复；全局／本项目筛选依据项目成员，固定与排除保持同一份全局列表。

添加时在原素材库与画板中连续点选、重复点选去重，也可显式固定仅画板可见的图片；不弹窗、不触发预览／插入创作输入／移动原画板节点。关闭素材库后保留画板上的添加提示，可继续点选；完成、Escape、收起常用面板、切换项目均退出点选。退出后原创作输入点击与拖入画板行为恢复。保留折叠状态／手动列表／移除跨重载、两行移除独立、窄抽屉两行横滚及滚轮转换回归。

直接检索专项：输入框仍聚焦时编辑阈值并点击检索，先保存一次新阈值再检索一次，结果按新阈值恢复排除素材；保存失败时不发出检索请求，回退已保存阈值并保留排除项。

队列专项：延迟全局固定 A，切换到本项目并排队固定 B，随后让 B 失败；队列结束必须完成当前范围读取，保留 A、排除失败的 B，结束 loading 并恢复检索按钮。

截图保存在本机 `apps/desktop/.tmp/canvas-frequent-assets/`：`default-threshold.png`（默认 10）、`light-wide.png`、`light-narrow.png`、`dark-narrow.png`、`picking-light.png`、`picking-dark.png`、`empty-manual.png`、`collapsed.png`（其余使用自定义 3）。旧 `picker-*` 截图属于已取消的弹窗方案，不能作为当前交付证据。浏览器测试使用模拟接口，不替代 Rust SQLite 的真实筛选、排序与持久化单元测试，也不替代原生跨 WebView 拖放验收。
