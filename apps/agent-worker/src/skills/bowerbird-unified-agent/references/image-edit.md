# 图片编辑

按用户要求确定最终主体、修改范围，以及每张参考图提供的属性。把这些职责写入生成步骤目标；未要求修改的内容沿用底图。

参考图只控制指定属性。例如姿势来源提供动作，饰品来源提供饰品，风格来源提供视觉语言。来源中的其他人物、服装、背景或文字不随该属性一起迁移。

看图时选择当前缺少的事实所对应的 focus，复用已有观察。看不清或未展示的细节保留为不确定信息。

如果确有参考串扰或已有失败证据，可以隔离冲突属性后分步编辑；后续编辑使用前一步结果作为底图。额外步骤应解决具体问题，参考图数量本身不决定步骤数。

控制参考可表达姿态轴线、轮廓、接触点或遮挡边界。使用时注明它只控制的属性，并排除示意线与标注进入成品。干净的产品或饰品参考可以直接使用。
