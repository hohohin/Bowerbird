## 2. 新共享能力

- 多张普通生成结果可以按原序作为新创作参考；仅明确继续/重试或唯一父结果时接回原轮次，保留精确节点身份。
- WPS HTML / TSV / Markdown 粘贴到内容卡二维格子，整卡/单格/Agent 往返保留行列、空格和格内换行。旧 `columns+rows` 在读边界合为可见二维行列。
- 循环按同一二维表格的可见行处理，表头也是一行；新「当前轮次」出口为原项号的纯数字。冻结输入、停止接续和原请求恢复保持。
- 本机 DSH / Codex 生图通过普通生成会话提交，冻结默认 provider 并保存 job/turn；收到持久化提交凭据后继续，循环不等待图片生成。图像进度/结果属于独立普通会话，已交付的生成任务不随工作流停止而取消；旧内部生图请求沿原协议取回。
- 普通会话图片独立点击和常显输出端口、拖入素材标注、草稿引用已移除节点恢复，同步对应前后端与测试。
- Windows Codex 工作目录写入预检保持 `cfg(windows)`；Mac 沿原 workspace-write 策略，不移植 Windows 沙箱参数。共享部分保留有界 CLI 错误尾部和缺结果说明。
